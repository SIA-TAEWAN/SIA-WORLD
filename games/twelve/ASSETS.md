# 시아열두길 — 그림·소리 현황과 만들 것

## 지금 쓰는 것 (전용 그림 없음)

- **대원**: 공용 십이지 전신 그림 `shared/images/zodiac/full/<id>.png` 한 장 (오른쪽을 본다 → 왼쪽으로 갈 때 뒤집는다). 걸을 때 위아래로 흔들고, 구를 때 한 바퀴 돌리고, 맞으면 분홍·강해지면 노랑으로 물들인다. 메뉴는 `face/<id>.png`.
  - 고양이는 그림이 없다 (숨김 상태). 화면에 나오게 되면 글자 그림(🐱 동그라미)으로 대신 그려진다.
- **요괴·보스·바닥·터짐**: 시아디펜스 그림을 `public/art/` 에 복사했다 — 요괴 9종 `e-*`, 보스 12종 `b-*`, 바닥 4종 `tile-*`, 터짐 `fx-pop`.
  - 정예 = 같은 요괴를 1.35배로 + 발밑 노란 테.
- **코드로 그리는 것** (`src/scenes/GameScene.ts`):
  - 맵: 바닥색 + 바닥 무늬 절반 섞기, 벽(덤불 점 + 굵은 갈색 테두리), 물(하늘색 + 물결). 16줄짜리 조각 캔버스에 한 번만 그린다.
  - 공격 예고(분홍 범위가 차오름), 베기 자국, 화살·창·구슬·불, 번개, 화살 비·회오리·독안개 범위, 체력 바, 출구(동그라미 + 🔒/🚪), 숨은 상자(🎁), 바라보는 방향 세모.
  - 피해 숫자: 숫자 10개를 캔버스에 한 번 그려 BitmapText 로 찍는다.
- **버튼 그림**: 글자 그림(이모지) — 무기 🗡️🔱🏹🪭, 스킬·고유 스킬 아이콘은 `data/weapons.ts` · `data/heroes.ts` 의 `icon`.
- **소리**: 공용 `shared/sound.js` 의 기존 효과음만 쓴다 (survSlash · survShot · survPop · survHurt · survBossWarn · survBossDown · survChest · survLevel · tankHeal · tankBoom · boost · jump · goal · newRecord · fold · win · lose · click 등). 새 소리는 9단계.

- **로비 카드**: `shared/images/card-twelve.png` (640×400) 는 기존 그림(대원 셋 · 1지형 요괴·보스 · 들판 바닥)을 모아 `scripts/make-card.py` 로 만든 임시 그림이다. 다른 게임 카드처럼 한 장면으로 그린 전용 그림이 필요하다 (아래 표).
- **끝없는 탑**: 전용 그림 없음. 층의 지형(10층마다 바뀐다)에 맞는 바닥·요괴·보스 그림을 그대로 쓴다.

## 그림을 넣는 방법 (시아돌격대와 같은 방식)

1. `public/art/<이름>.png` 로 넣는다.
2. `src/scenes/art.ts` 의 `ART_FILES` 에 이름을 적는다 (타입 `OptionalArt` 에 이름이 없으면 더한다).
3. `GameScene` 에서 `hasArt('<이름>')` 이면 그 그림을, 아니면 지금의 코드 그림을 쓰게 한다 (요괴·보스·바닥처럼 `artFor()` 가 돌려주는 이름은 파일만 바꿔도 바로 쓰인다).
4. SpriteCook 으로 만들었으면 `spritecook-assets.json` 에 `{asset_id, sha12, label}` 을 적는다 (지금은 빈 목록).
