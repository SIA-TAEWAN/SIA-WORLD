## 지금 쓰는 것

- **대원**: 전용 시트 `hero-<id>` (앞 · 옆 · 뒤 세 칸, 10단계). 바라보는 쪽의 칸을 쓰고 왼쪽은 뒤집는다. 걸을 때 위아래로 흔들고, 구를 때 한 바퀴 돌리고, 맞으면 분홍·강해지면 노랑으로 물들인다. 시트를 못 읽으면 공용 전신 그림 `shared/images/zodiac/full/<id>.png` 한 장. 메뉴는 `face/<id>.png`.
  - 고양이도 공용 그림(`shared/images/zodiac/face|full/cat.png`)을 쓴다 (보통 모드를 끝낸 뒤에만 보인다).
- **최종보스 어둑시니**: 전용 그림 `b-final`(512×512) 한 장을 단계마다 키워 쓴다 (230 → 262 → 296). 어려움 모드는 분홍빛을 입힌다. 못 읽으면 코드 그림(`enemy-fallback`).
- **엔딩 4장 · 고양이 등장 장면**: 기존 그림(보스 · 대원 얼굴 · 고양이 전신)을 모은 장면이다. 전용 그림은 `public/art/ending-1~4.png` · `cat-scene.png` 로 넣고 `ART_FILES` 에 적으면 바로 쓰인다.
- **요괴·보스·터짐**: 시아디펜스 그림을 `public/art/` 에 복사했다 — 요괴 9종 `e-*`, 보스 12종 `b-*`, 터짐 `fx-pop`. 바닥 4종 `tile-*` 은 `ART_FILES` 에서 지형 바닥을 뺐을 때만 쓰는 예비다(지금은 받지 않는다).
- **지형 바닥**: `floor-r01`~`floor-r12` (시아핑거 그림 복사) 를 320px 그대로 이어 깐다. 못 읽으면 바닥색만.
  - 정예 = 같은 요괴를 1.35배로 + 발밑 노란 테.
- **코드로 그리는 것** (`src/scenes/GameScene.ts`):
  - 맵: 바닥색 + 지형 바닥 무늬, 벽(덤불 점 + 굵은 갈색 테두리), 물(하늘색 + 물결). 16줄짜리 조각 캔버스에 한 번만 그린다.
  - 공격 예고(분홍 범위가 차오름), 찌르기·회전 자국, 번개, 화살 비·회오리·독안개 범위, 체력 바, 바라보는 방향 세모. (칼 베기 자국 · 화살·창·구슬·불 · 출구 · 숨은 상자는 10단계부터 그림 — 못 읽으면 코드 그림)
  - 피해 숫자: 숫자 10개를 캔버스에 한 번 그려 BitmapText 로 찍는다.
- **버튼 그림**: 무기·무기 스킬·물약은 아이콘 그림 `ic-*` (`ui/icons.ts`), 고유 스킬·구르기는 글자 그림(이모지 — `data/heroes.ts` 의 `icon`).
- **소리**: 공용 `shared/sound.js` 에 열두길 소리 6개를 더했다(9단계, ZzFX 방식 — 다른 게임의 소리는 그대로): `twelveSlash`(칼·창 베기) · `twelveBow`(활) · `twelveMagic`(부채 구슬) · `twelveHurt`(피격) · `twelveRare`(레어·열쇠 드랍) · `twelveLevel`(결과 화면의 레벨 업). 나머지는 기존 소리(survShot · survPop · survBossWarn · survBossDown · survChest · survLevel · tankHeal · tankBoom · tankLaser · boost · jump · goal · newRecord · fold · coin · click 등). `tests/sound.test.ts` 가 쓰는 이름이 모두 목록에 있는지 본다. `shared/sounds/<이름>.ogg|.mp3` 를 넣으면 그 파일로 바뀐다.
- **진동**: 피격 30ms · 레어 드랍 40-40-80ms (`app.ts` 의 `hooks.hurt` · `hooks.rare`, 설정의 진동을 끄면 없음. 아이폰 사파리는 `navigator.vibrate` 가 없어 아무 일도 없다).

- **로비 카드**: `shared/images/card-twelve.png` (640×400) 는 SpriteCook 으로 그린 한 장면이다 (10단계, `art/build.py` 가 자른다). `scripts/make-card.py` 는 예전 임시 그림을 만들던 것 — 돌리면 카드를 덮어쓰니 돌리지 않는다.
- **끝없는 탑**: 전용 그림 없음. 층의 지형(10층마다 바뀐다)에 맞는 바닥·요괴·보스 그림을 그대로 쓴다.

## 그림을 넣는 방법 (시아돌격대와 같은 방식)

1. `public/art/<이름>.png` 로 넣는다.
2. `src/scenes/art.ts` 의 `ART_FILES` 에 이름을 적는다 (타입 `OptionalArt` 에 이름이 없으면 더한다).
3. `GameScene` 에서 `hasArt('<이름>')` 이면 그 그림을, 아니면 지금의 코드 그림을 쓰게 한다 (요괴·보스·바닥처럼 `artFor()` 가 돌려주는 이름은 파일만 바꿔도 바로 쓰인다).
4. SpriteCook 으로 만들었으면 원본을 `art/raw/<이름>.png` 로 받고 `art/ids.tsv` 에 `이름<탭>asset_id` 를 적은 뒤 `art/build.py` 의 `SIZES` 에 크기를 더해 돌린다 (`public/art` 와 `spritecook-assets.json` 을 새로 쓴다).
