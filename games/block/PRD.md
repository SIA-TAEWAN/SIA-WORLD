# 시아블록 (가제) 구현 요청

SIA-WORLD 저장소(SIA-TAEWAN/SIA-WORLD, 로컬 C:\Claude\SIA-WORLD)에 새 게임 **시아블록(가제)**을 `games/block`으로 추가해 줘.
**블록 블라스트를 그대로 따라가는** 1인용 블록 퍼즐이야. 아래에 나오는 블록 조각 3개를 끌어다 8×8 판에 놓고, 가로나 세로 한 줄이 꽉 차면 지워져.
**나온 조각을 다 놓지 못하면 게임 끝**이고, 그때까지의 점수로 랭킹에 올라가는 방식이야. 장애물, 스테이지, 특수 능력은 없어.
그림과 연출은 **시아팡팡(`games/pang`)의 정령**을 가져다 써서 SIA-WORLD 느낌을 내.

## 0. 시작 전에 먼저 할 일
코드를 쓰기 전에 아래를 먼저 살펴보고, 무엇을 그대로 가져다 쓸지 짧게 한국어로 보고해 줘.
- CLAUDE.md, DESIGN.md
- **`games/pang`(시아팡팡)**: 정령 그리기(`src/game/spirits.js`), 파티클·효과(`src/ui/app.js`), 정령 마당과 배경(`src/ui/scene.js`), 콤보 글자·칭찬·진동 연출, 화면 구조, 서버 함수(`111_pang.sql`)
- `games/finger`의 `finger-finish` (입력을 서버에서 다시 돌려 검증하는 방식)
- `shared/wallet.js`(시아코인), `shared/ranking-dialog.js`, `shared/presence.js`, `shared/sound.js`
시아팡팡 코드를 복사하기보다, 두 게임이 같이 쓸 부분(정령 그리기, 파티클)은 공용으로 빼는 게 나은지 먼저 판단해서 알려줘. 시아팡팡 동작이 바뀌면 안 돼.

## 1. 기본 사항
- 기술: 시아팡팡과 같은 구조 (Vite 패키지, 캔버스 그리기), Supabase (기록·랭킹), 기존 배포 방식 그대로
- 로그인 필수 (게스트 플레이 없음). **1인 전용**
- **화면: 세로**, 시아팡팡과 같은 모바일 세로 우선(480px 띠), PC 지원. 가로본능 게임이 아님
- **모드는 하나**: 죽을 때까지 점수를 쌓는 방식. 목숨 제한 없이 몇 판이든 할 수 있음
- 십이지 캐릭터를 쓰지 않음 (정령만). 캐릭터 고르기가 없어 고양이 구매 대상이 아님
- 판 크기, 조각 모양과 나오는 비율, 점수 수치는 데이터 파일로 분리
- **게임 로직은 순수 함수**(판 상태 + 놓기 → 새 판 상태)로. 무작위는 시드 Rng로만. 같은 시드 + 같은 놓기 기록이면 결과가 항상 같아야 함 (서버 검증의 바탕)

## 2. 규칙 (블록 블라스트와 같게)
- 판 **8×8**, 처음엔 비어 있음
- 아래에 조각 **3개**가 나옴. 하나씩 끌어다 판의 빈 곳에 놓음. 순서는 자유
- **조각은 돌릴 수 없음**
- 3개를 모두 놓으면 새 조각 3개가 나옴
- **가로 한 줄 또는 세로 한 줄이 꽉 차면 지워짐.** 여러 줄이 동시에 차면 모두 지워짐 (가로·세로 같이도)
- **남은 조각 중 어느 것도 놓을 곳이 없으면 게임 끝** (3개를 다 쓰지 못하면 죽음)
  - 놓을 수 없는 조각은 흐리게 표시
  - 끝날 때 판의 블록들이 위에서부터 회색으로 바뀌는 연출 후 결과
- 되돌리기·이어하기(부활)·조각 바꾸기 없음

**조각 모양**
| 종류 | 모양 |
|---|---|
| 점 | 1칸 |
| 막대 | 가로·세로 2, 3, 4, 5칸 |
| 네모 | 2×2, 3×3 |
| 직사각형 | 2×3, 3×2 |
| 작은 ㄱ자 | 3칸 (방향 4가지) |
| 큰 ㄱ자 | 5칸 (방향 4가지) |
| T자 | 4칸 (방향 4가지) |
| S·Z자 | 4칸 (가로·세로) |

- 모양별로 나오는 비율은 데이터로. 처음에는 작은 조각이 조금 더 많고, 점수가 오를수록 큰 조각 비율이 조금씩 오름 (블록 블라스트처럼 뒤로 갈수록 빡빡해지게)
- **자비 규칙**: 새 조각 3개를 뽑을 때, 판에 놓을 수 있는 조각이 하나도 없으면 한 번만 다시 뽑음 (그래도 없으면 그대로 → 게임 끝). 시작하자마자 억울하게 끝나는 일 방지

## 3. 점수
- 칸 하나 놓을 때마다 +1점 (조각 칸 수만큼)
- 줄 지우기: 1줄 100, 2줄 동시 300, 3줄 600, 4줄 이상 1,000 + 줄마다 400
- **콤보**: 줄을 지운 놓기가 연달아 이어지면 콤보 +1. 줄 지우기 점수 × (1 + 콤보 × 0.5). 줄을 못 지운 채 **3번** 놓으면 콤보가 끊김
- **판 비우기**(판에 블록이 하나도 없음): +3,000
- 화면 위에 지금 점수와 내 최고 점수. 최고 점수를 넘는 순간 "최고 기록!" 연출
- 수치는 데이터로. 블록 블라스트를 해 보고 손맛이 비슷하게 맞춰 줘

## 4. 정령 블록 (그림과 연출만)
- 조각마다 정령 하나가 들어 있고, 조각의 모든 칸이 그 정령 모습으로 그려짐 (시아팡팡 정령 그림 재사용, 칸 크기에 맞게)
- 정령은 **색깔 역할만** 함. 게임 규칙에는 영향 없음 (블록 블라스트의 색깔 블록과 같음)
- 줄이 지워질 때 그 줄의 정령들이 한 칸씩 차례로 튀어 오르며 사라짐 (시아팡팡 파티클)
- 콤보 2부터 판 가운데 'N 콤보!' 글자(콤보가 늘수록 커짐) + 진동 + 칭찬 한마디(좋아요·멋져요·대단해요, 5 이상 '정령 폭풍!') — 시아팡팡 연출 재사용
- 판 아래 남는 공간이 넉넉하면 **정령 마당**: 정령들이 뛰놀다가, 줄이 지워지면 그 줄에 있던 정령들이 기뻐하고, 콤보 3 이상이면 모두 뜀 (시아팡팡 정령 마당 재사용. 게임에는 영향 없음)

## 5. 화면
1. **메인**: 위 띠(← SIA WORLD · 시아코인 · 랭킹), 로고, 내 최고 점수, 큰 [시작] 버튼, 이번 주 1등 점수
2. **게임**: 위에 점수·최고 점수·멈춤 버튼 / 가운데 판 / 아래 조각 3개 / 그 아래 정령 마당
3. **결과**: 이번 점수, 최고 점수(새 기록이면 크게 연출), 지운 줄 수, 최대 콤보, 랭킹 순위, 시아코인 → [다시 하기] [메인] [랭킹]
- 멈춤: [이어서] [처음부터] [메인으로] [소리]

## 6. 조작
- **모바일**: 조각을 손가락으로 끌어서 놓기
  - 끄는 동안 조각이 손가락보다 약간 위에 떠서 보임 (손가락에 가리지 않게)
  - 판 위에 **놓일 자리 그림자**와 **지워질 줄 미리 보기**(반짝임)
  - 가까운 칸으로 자석처럼 딱 붙는 느낌
  - 놓을 수 없는 자리에서 손을 떼면 조각이 제자리로 돌아감
  - 놓을 때 짧은 진동(지원 기기만, 설정에서 끄기)
- **PC**: 마우스로 끌어서 놓기. 키보드는 1·2·3으로 조각 고르고 방향키로 위치 옮긴 뒤 Enter로 놓기

## 7. 랭킹
| 탭 | 기준 |
|---|---|
| 전체 | 최고 점수 → 먼저 달성한 순 (각자 최고 기록 하나) |
| 이번 주 | 이번 주(월요일 시작) 최고 점수 → 먼저 달성한 순. 매주 새로. 지난주 1등도 볼 수 있게 |

- 표시: 순위, 아이디, 점수, 달성 날짜. 내 순위는 항상 표시. 상위 순위 아이콘은 다른 SIA-WORLD 랭킹과 통일

## 8. 기록과 검증 (Supabase, 기존 규칙에 맞춰)
- 판은 기기에서 돌아가고, 서버는 시작·끝·기록을 맡음
- `block_state()` → { best, weekBest, siaCoins } / `block_start()` → { run, seed } / 판이 끝나면 기록 제출
- **서버가 다시 돌려 점수를 확정**: 기록은 "몇 번째 조각을 어느 칸에" 목록뿐이라 아주 작음. Edge Function `block-finish`가 같은 게임 로직(`supabase/functions/_shared/block/`)으로 시드부터 다시 돌려 점수를 계산하고, 기기가 보낸 점수와 다르면 랭킹에 넣지 않음 (`finger-finish` 방식)
  - 게임 로직은 브라우저와 서버가 같은 파일을 씀 (Deno 규칙: 상대 경로 + `.ts` 확장자)
  - 상식 검사도 같이: 내 판이고, 안 끝났고, 시작한 지 너무 오래되지 않았고, 놓은 횟수 × 0.3초보다 빨리 끝나지 않음
- 시아코인: 끝낸 판마다 1개 (`_grant_sia_coin`). 멈춤에서 나간 판은 없음
- 마이그레이션 번호는 `ls supabase/migrations`로 확인하고 다음 번호로. 이미 올라간 마이그레이션은 고치지 않음
- 제출에 실패하면 기기에 임시 보관 후 재전송

## 9. SIA-WORLD 연결
- 로비 `shared/games.js`에 시아블록 추가 (세로 게임이라 가로본능이 아니라 로비에 바로)
- CLAUDE.md의 "Adding a game means" 목록: `game_open:block`(기본 닫힘, 관리자가 로비에서 염), `shared/presence.js` 채널, `shared/ranking-dialog.js` 랭킹 탭, `deploy.yml` 빌드·복사 + Edge Function `block-finish` 배포, PWA head 블록
- 로비 카드 그림 `shared/images/card-block.png` (시아팡팡 카드처럼 정령 배경 + 정령 블록)

## 10. 디자인과 사운드 (DESIGN.md 기준)
- 시아팡팡과 같은 색과 느낌 (보드 밤하늘 바탕, 크림 판 + 갈색 외곽선). 정령 그림은 코드 그림 재사용
- 블록 칸 그림: 정령 색 바탕 + 정령 얼굴. 칸이 작아도 정령이 구별되게 (색 + 모양)
- 배경음: `shared/audio/bgm/block/main.mp3`(평소), `boss.mp3`(최고 기록을 넘긴 뒤부터). 공용 결과음은 `common/win.mp3`(새 기록), `lose.mp3`(게임 끝)
- 효과음: 조각 집기, 놓기, 놓을 수 없음, 줄 지우기(줄 수에 따라 높아짐), 콤보, 판 비우기, 게임 끝, 새 기록. 없으면 `shared/sound.js`의 ZzFX 소리 추가

## 11. 하지 않는 것
장애물, 스테이지·목표, 정령 특수 능력, 목숨, 되돌리기, 조각 돌리기, 이어하기(부활), 멀티플레이·대전, 결제·유료 재화·광고, 게스트 플레이

## 12. 진행 순서
1. **게임 로직**: 8×8 판, 조각 모양, 놓기, 줄 지우기, 끝 판정, 점수·콤보·판 비우기, 자비 규칙. vitest 테스트 먼저 (같은 시드 + 같은 놓기 → 같은 점수, 놓을 곳이 없으면 끝)
2. **게임 화면**: 끌어서 놓기, 자리 그림자, 지워질 줄 미리 보기, 정령 블록 그림, 줄 지우기·콤보 연출, 결과 화면. 이 단계에서 폰으로 직접 해 보고 내가 확인한 다음 넘어가기
3. **기록과 랭킹**: `block_start`, `block-finish` Edge Function, 랭킹(전체·이번 주), 시아코인
4. **정령 마당, 디자인·사운드 적용**
5. **SIA-WORLD 연결**: 로비 카드, presence, 배포

**개발용 설정**: `?local=1`(로그인 없이, 기록은 이 기기에만), `&seed=123`(같은 조각 순서로 시험)

각 단계가 끝날 때마다 `npm test`와 `npm run build`가 통과해야 하고, 바뀐 점과 내가 폰에서 확인할 것을 한국어로 정리해 줘.
커밋은 한국어로 하고, **push는 내가 확인한 다음에** 할 거니까 하지 마.
