# 시아의탑 (games/tower) — PRD

게임 id `tower`, 개발 포트 5298, 마이그레이션 `104_tower.sql`.

## 게임 개요 (사용자 지시 원문 요약)
- Phaser 3 기반 1인용 탑뷰 도트 액션 RPG. 4방향 이동.
- 100층에 있는 소원을 들어주는 구슬을 얻기 위해 1층부터 100층까지 오른다.
- 전체 목표는 100층, 약 10시간. 이번 범위는 "캐릭터 만들기 + 1~10층 끝까지 플레이" (MVP).
- 데이터와 구조는 100층까지 확장 가능 (층·방·적·구슬·아이템을 JSON 데이터로 분리).

## 캐릭터 만들기 (게임 시작 시)
- 순서: 성별(남/여) → 머리 모양(성별마다 4종, 총 8종) → 얼굴 4종 → 옷 4종. 총 128가지 조합.
- 몸(남/여) 위에 얼굴 → 옷 → 머리 순서로 레이어를 겹쳐 그린다. 레이어마다 4방향 × (대기 1, 걷기 4, 공격 3) 프레임, 모든 레이어의 프레임 위치가 같다.
- 고르는 동안 가운데 미리보기 캐릭터가 바로 바뀐다.
- 이름은 따로 입력받지 않고 SIA-WORLD 계정 이름(닉네임)을 쓴다.
- 만든 뒤 외형 변경은 시아코인 30개.
- 아트는 임시 도트(코드로 만든 플레이스홀더). 나중에 스프라이트 시트 파일만 바꾸면 되게. 타일 16px, 캐릭터 레이어 32×32px, 화면은 정수 배율 확대(픽셀 선명).

## 전투·성장 규칙
- 무기는 칼 하나 고정. 강화 없음. 레벨과 구슬로만 강해진다.
- 기본 공격: 칼 3타 콤보.
- 레벨 최대 99. 1레벨 체력 100 / 공격력 10 / 방어력 5 / 혼력 50, 레벨당 +25 / +3 / +2 / +2.
- 경험치는 평균 한 층에 1레벨씩. 죽어서 다시 오른 층(이미 깬 층)에서는 경험치 절반.
- 혼력(MP): 스킬 사용 시 소모, 기본 공격이 적에게 맞으면 차오른다.
- 구슬: 무기 하나에 1개만 장착. 메뉴에서 언제든 교체. 장착하면 기본 스킬 사용 가능.
  같은 구슬을 또 얻거나 구슬 조각 5개를 모으면 각성 스킬이 열린다.
- 화폐는 엽전(단위: 냥). 적·상자·보스에서 얻는다.

## 탑 구조
- 한 층 = 방 3~5개 + 계단. 방 템플릿을 층마다 다르게 조합. 카메라는 캐릭터를 따라간다.
- 방 종류: 전투방(문이 잠기고 적을 다 잡으면 열림), 퍼즐방(특정 구슬이 있어야 풀림), 보물방(구슬·구슬 조각·회복약·엽전), 계단.
- 10층마다 반복: 1~4층 일반, 5층 휴식(상점), 6~8층 일반, 9층 정예, 10층 보스.
- 저장: 10층 보스를 깨면 체크포인트. 죽으면 마지막 체크포인트(1·11·21…층)부터 다시. 레벨·경험치·엽전·구슬·구슬 조각·외형은 잃지 않는다. 서버에 저장해 다른 기기에서도 이어 한다.
- 1~10층 테마: "탑의 입구(돌 복도)". 보스: 문지기 골렘(기준 레벨 10, 2~3분 걸리는 체력).
- 일반 적은 그 층 기준 레벨 캐릭터의 기본 공격 3~5번에 쓰러진다.

## 휴식층 상점 (1구역 가격, 구역마다 약 1.5배)
| 품목 | 효과 | 가격 | 제한 |
|---|---|---|---|
| 회복약(소) | 체력 30% 회복 | 20냥 | 없음 |
| 회복약(대) | 체력 70% 회복 | 60냥 | 없음 |
| 혼력 물약 | 혼력 50% 회복 | 40냥 | 없음 |
| 정화 부적 | 독·화상·둔화 해제 | 30냥 | 없음 |
| 지도 두루마리 | 다음 층 방 배치·보물방 표시 | 50냥 | 없음 |
| 구슬 조각 | 각성 재료 | 300냥 | 휴식층당 1개 |
| 부활 부적 | 쓰러지면 체력 50%로 자동 부활 | 500냥 | 1개만 소지, 최종보스전 사용 불가 |
한 구역(10층)에서 회복약(대) 10개 정도 살 수 있는 만큼 엽전이 나온다.

## 화면
- HUD: 왼쪽 아래 체력 바, 혼력 바, 레벨·경험치, 장착 구슬 칸. 오른쪽 위 층수와 엽전.

## MVP 완료 기준
캐릭터 만들기 → 1층 시작 → 2층 쥐 구슬, 7층 소 구슬 → 5층 상점 → 9층 정예 → 10층 문지기 골렘 처치 → 체크포인트 저장까지 끊김 없이.
로비에서 시아의탑으로 들어가고, 로그인과 저장이 기존 게임과 같은 방식.

## 메인이 정한 것 (사용자에게 묻지 않고 추천안대로)

- 로비 등록은 닫힌 상태(`game_open:tower = false`, 관리자만 들어가고 관리자가 로비에서 연다) — 이전 새 게임들과 같다.
- 조작: 키보드(WASD/방향키 이동, J·Space 공격, K 스킬, L 각성, I·Esc 메뉴, E 상호작용) + 폰 터치(왼쪽 가상 조이스틱, 오른쪽 공격·스킬·각성 버튼). SIA WORLD 는 폰으로 많이 한다.
- 구슬 조각은 공용(어느 구슬이든). 메뉴에서 장착한 구슬에 조각 5개를 써서 각성을 연다. 같은 구슬을 두 번째로 얻으면 그 구슬 각성이 바로 열린다(이미 열렸으면 조각 1개로 바꿔 준다).
- 한 층 안에서는 저장하지 않는다. 계단을 오르면(층을 깨면) 저장. 중간에 나가면 다음에 그 층 처음부터. 죽으면 체크포인트로.
- 시아코인 적립: 층을 처음 깰 때마다 1개(층마다 평생 한 번, `_grant_sia_coin` ref `floor:<n>` — 15초·하루 100개 한도는 그 함수 안에서). 다른 게임과 같은 "서버가 끝을 보는 판" 규칙.
- 랭킹: 오른 최고 층 → 레벨 → 먼저 달성한 순 (`tower_ranking` 뷰), 로비 랭킹 창에 '시아의탑' 탭.
- 관리자 계정은 들어올 때 엽전·시아코인 1만 (102 와 같은 방식).
- 결과 지어내기 방지는 가볍게(친목용): 서버는 값 범위·층 건너뛰기만 확인한다.

## 서버 약속 (104_tower.sql, 클라이언트 `src/net/api.ts` 가 이것만 쓴다)

표 `tower_profiles(user_id, look jsonb|null, data jsonb, level, best_floor, best_at, look_changes, …)`. 클라이언트는 표를 직접 읽거나 쓰지 않는다.

- `tower_state() → { look, data, bestFloor, siaCoins, lookPrice }`
  - 처음이면 행을 만든다(look = null → 캐릭터 만들기 화면).
  - `data` 는 클라이언트 진행 상태 JSON (처음은 `{}`). 모양은 클라이언트가 정한다(아래).
- `tower_set_look(p_look jsonb) → { look, siaCoins, paid }`
  - `p_look = { sex: 'm'|'f', hair: 0~3, face: 0~3, outfit: 0~3 }` 아니면 예외 `'bad look'`.
  - 처음(look 이 null)은 무료. 같은 외형이면 그대로(paid false). 다른 외형이면 시아코인 30 차감, 모자라면 예외 `'not enough sia coins'`.
- `tower_save(p_data jsonb, p_cleared int default null) → { bestFloor, gotCoin, siaCoins }`
  - 진행 저장. `p_cleared` = 방금 깬 층(계단을 오름 / 10층은 보스 처치). 없으면 그냥 저장(상점·메뉴·죽음).
  - 서버 확인: `p_data` 는 객체이고 32KB 이하, `level` 1~99, `exp`·`coins` 0 이상, `floor` 1~100, `checkpoint` 는 1·11·21…91 이면서 `best_floor + 1` 이하, `p_cleared` 는 1~100 이면서 `best_floor + 1` 이하(건너뛰기 금지). 어기면 예외 `'bad save'`.
  - `p_cleared > best_floor` 면 best_floor 갱신. `p_cleared` 가 있으면 시아코인 시도(층마다 평생 한 번).
  - `level` 열은 `data.level` 로 맞춘다(랭킹용).

클라이언트 `data` (권장 모양, 클라이언트 normalize 가 지킨다):
```
{ v: 1, level, exp, coins, floor, checkpoint, best,          // floor = 다음에 시작할 층, best = 깬 최고 층
  orbs: { rat: 1, ox: 2 },  awakened: ['ox'],  shards: 0,  equipped: 'rat' | null,
  items: { potionS, potionL, mana, cleanse, map, revive },
  shopShard: [5],          // 조각을 산 휴식층
  mapped: [6] }            // 지도 두루마리로 밝힌 층
```

## 2차 (2026-11-25): 층 시간 늘리기 · 11~20층 · 구슬 14개 · 배경음 · 관리자 엽전 (105)

### 한 층 3~4분 (사용자 결정)
- 방을 키우고(안쪽 15×11 → **19×13**, 예전 템플릿은 가운데에 놓고 둘레를 채운다 — 퍼즐·보스방은 기둥으로 채워 예전 크기를 지킨다), 방 수를 늘렸다:
  큰 길 전투방 3~4개 + 곁방 2~3개(보물·퍼즐 모두). 전투방마다 **무리(waves) 3번**: 한 무리(3~5마리)를 다 잡으면 1초 뒤 같은 적 자리에 다음 무리.
- 적을 단단하게 하지 않았다(타수 그대로 3~5). 한 층 적 수가 3~4배라 한 마리 몫을 줄였다: 경험치 × `killExp`, 엽전 × `killCoins`, 공격력 × `packAtk` (enemies.json).
- 싸움 밖(잠긴 방이 없을 때) 체력·혼력이 천천히 회복된다(`growth.restRegen`, 1초에 2.5%·2%) — 방을 돌며 퍼즐·보물을 찾는 동안.
- 새 퍼즐 '발판'(어느 층이든): 방의 발판을 시간(3 + 2.5×개수 초) 안에 모두 밟으면 철문이 열린다. 늦으면 다시 올라온다.
- 문지기 골렘은 그대로 (방 둘레를 기둥으로 채워 싸움터 크기도 예전 그대로).
- 휴식층에도 보물방 하나.
- 사람은 봇보다 느리다고 보고 봇 기준 2~3분을 맞춘다 (PROGRESS.md '밸런스').

### 2구역 11~20층 "이끼 낀 회랑" (theme `moss`, 내가 정함)
탑의 입구를 지나면 덩굴과 이끼가 뒤덮은 옛 회랑. 옛날 소원을 빌러 온 이들이 켜 두던 화로들이 꺼진 채 남아 있고, 물길 사이에 배를 매던 말뚝이 박혀 있다.
여의주(소원 구슬)를 얻어 용이 되려는 이무기가 이 회랑의 끝을 지킨다 — 용 구슬(12층)과 뱀 구슬(17층)이 이 구역에서 나오는 까닭.

| 층 | 구성 |
|---|---|
| 11~14 | 일반 (12층 용 구슬 받침대) |
| 15 | 휴식·상점 (값 ×1.5) |
| 16~18 | 일반 (17층 뱀 구슬 받침대) |
| 19 | 정예 고목 수호자 |
| 20 | 보스 이끼 이무기 → 체크포인트 21 |

| `moth` | 이끼 나방 | 16 | 11층~ | 박쥐처럼 날아와 부딪히고 물러남, 독 가루 |
