## 밸런스 (봇 측정, `npm run bot -- 6 20` · 3차는 `npm run bot -- 4 50`)

가정: **사람은 봇보다 약 1.4~1.5배 느리다** (봇은 길을 바로 알고, 메뉴·상점·안내를 읽지 않고, 멈추지 않는다). 그래서 봇 기준 한 층 2~3분을 맞추면 사람은 3~4분.
이 가정은 아직 사람으로 재지 않았다 — 열고 나서 실제 시간을 보고 `floors.json` 의 combat · waves · pack 으로 맞춘다.

- 1→20층 합계 봇 약 44분 (예전 1→10층 약 8분). 사람 ×1.4~1.5 가정이면 일반층 약 3~4분, 20층까지 약 1시간. 휴식층은 상점·메뉴를 사람 손으로 하니 봇보다 훨씬 길다.
- 쓰러짐: 씨앗 6개 중 1개가 첫 골렘에서 한 번 (체크포인트 1층부터 다시 → 두 번째에 깸). 이무기는 6개 모두 첫 도전에 깸.

- 층당 레벨: 9층을 깬 뒤 Lv 10~11, 10층 뒤 Lv 12~13 (첫 도전), 19층 뒤 Lv 21~22 (2구역은 한 층에 약 1.1레벨)
- 일반 적 타수: 평균 3~4 (1~20층 `hitsToKill` 모두 3~5)
- 엽전: 한 구역에서 번 것 약 750~900냥 (회복약(대) 약 10~13개, 2구역은 값 ×1.5 에 엽전도 ×1.5)
- 문지기 골렘: 그대로 (봇 Lv10~12, 100~135초, 첫 도전에서 가끔 진다). 이끼 이무기: 봇 Lv21~23, 135~150초

3차 (1→50층 씨앗 4개, `npm run bot -- 4 50`):
- 1→50층 합계 봇 약 117분. 사람 ×1.4~1.5 가정이면 50층까지 약 3시간 (100층 10시간 목표의 절반에 조금 못 미친다).
- 쓰러짐: 씨앗 4개 중 1개가 첫 골렘에서 한 번뿐, 21~50층은 모두 첫 도전에 깸.

- 엽전 (구역마다 번 것, 그 구역 값으로 회복약(대) 몇 개): 3구역 1555~1865냥 = 11.5~13.8개 · 4구역 2429~2684냥 = 12.0~13.2개 · 5구역 3811~4325냥 = 12.5~14.2개.

- x4·x8 층(전투방 4개가 나오기 쉬운 층)이 3~3.4분으로 가장 길다. 사람이 해 보고 길면 `floors.json` 의 combat 최대값을 3으로.

## 개발용 주소 (개발 서버 localhost 에서만)

`http://localhost:5298/games/tower/?local=1` — 로그인·서버 없이, 기록은 이 기기(`siatower:local`)에만.

| 붙이는 값 | 뜻 |
|---|---|
| `&reset=1` | 기기 기록을 지우고 캐릭터 만들기부터 |
| `&floor=15` | 그 층에서 바로 시작 (레벨도 그 층에 맞추고, 그 아래 층에서 받는 구슬을 준다 — 3층 이상 쥐, 8층 소, 13층 용, 18층 뱀, 23 토끼, 28 원숭이, 31 현무, 33 닭, 38 양, 43 개, 48 호랑이) |
| `&lv=10` | 레벨 |
| `&god=1` | 무적 |
| `&orbs=rat,ox` · `&orbs=all` | 구슬 (all = 16개 모두 — 아직 오를 수 없는 22~90층 구슬도). 첫 번째 것을 장착 |
| `&awaken=rat` · `&awaken=all` | 각성 |
| `&coins=1000` · `&shards=5` | 엽전 · 구슬 조각 |

예: 상점 `?local=1&floor=15&coins=900`, 골렘 `?local=1&floor=10`, 이무기 `?local=1&floor=20`, 동장군 `?local=1&floor=30` · 영등할미 `&floor=40` · 불가사리 `&floor=50`, 풍경 퍼즐 `&floor=34`, 전설 구슬 시험 `?local=1&floor=13&orbs=phoenix,whiteTiger,turtle,blueDragon&awaken=all&god=1` (메뉴의 구슬 탭에서 바꿔 낀다).
콘솔에서 `__towerGame.scene.getScene('tower').run` 으로 시뮬레이션 상태를 볼 수 있다 (테스트 모드에서만).
