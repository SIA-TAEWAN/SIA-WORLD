# 시아마을 구현 요청

SIA-WORLD 저장소(SIA-TAEWAN/SIA-WORLD, 로컬 C:\Claude\SIA-WORLD)에 새 게임 **시아마을**을 `games/village`로 추가해 줘.
빈 땅에 건물을 짓고, 시간이 지나면 쌓이는 자원을 거두어 마을을 키우는 게임이야. 십이지 12명이 주민으로 이사 와.
하루에 몇 번, 몇 분씩 들르는 게임이고, 다른 SIA-WORLD 게임과 연결되어 전체를 묶는 중심 역할을 해.

## 0. 시작 전에 먼저 할 일
코드를 쓰기 전에 아래를 먼저 살펴보고, 무엇을 그대로 가져다 쓸지 짧게 보고해 줘.
- 기존 게임들의 폴더 구조, Phaser 3 설정, 씬 구성
- 통합 로그인(아이디+비밀번호), Supabase 클라이언트 설정, 기존 랭킹 테이블 구조와 랭킹 화면
- **시아코인(SIA-WORLD 공통 재화)**: 공통 지갑 테이블과 "게임 한 판당 1코인" 적립 코드가 어디에 어떻게 구현되어 있는지. **게임별로 적립이 빠진 곳이 있는지 목록으로 확인해서 보고하고, 빠진 게임에는 같은 방식으로 추가해 줘**
- 각 게임의 기록 테이블(랭킹·전적): 기념물 조건 확인에 사용
- DESIGN.md (색, 글꼴, 버튼, 패널, 사운드 규칙)
- 십이지 캐릭터 이미지가 있는 위치와 형식
- SIA-WORLD 게임 선택 화면에 게임을 추가하는 방법
기존 공용 코드와 스타일을 최대한 재사용해 줘.

## 1. 기본 사항
- 기술: Phaser 3, Supabase DB, 기존 배포 방식 그대로
- 인원: 1인(내 마을 하나). 다른 사람 마을은 구경만 가능. 실시간 통신 없음
- 로그인 필수 (게스트 플레이 없음)
- 화면: 세로 9:16, 기준 해상도 720×1280. PC에서는 가운데에 세로 비율로 표시. 마을은 끌어서 이동, 확대/축소
- 한 번 접속: 3~5분
- **시간 계산은 서버 시간 기준** (기기 시계를 바꿔도 소용없게)
- 건물·자원·주민·부탁·레벨·가격 수치는 모두 데이터 파일로 분리

## 2. 화면 구성
- 마을 화면이 곧 메인 화면. 접속하면 바로 내 마을
- 위쪽: 마을 레벨과 경험치 바, 보유 자원(쌀·나무·돌·떡·엽전), 시아코인
- 아래쪽 메뉴: [짓기] [주민] [부탁] [기념물] [랭킹]
- 건물에 수확할 자원이 쌓이면 아이콘이 떠오름 → 누르면 수확
- 십이지 주민들이 마을을 걸어 다님. 누르면 한마디 하거나 부탁을 보여 줌

## 3. 핵심 흐름과 시간 규칙
1. 건물을 짓는다 (자원 소모, 짓는 데 시간이 걸림)
2. 생산 건물이 시간에 따라 자원을 만든다 (접속하지 않아도 쌓임)
3. 접속해서 수확한다
4. 모은 자원으로 건물을 더 짓거나 업그레이드하고, 주민 부탁을 들어준다
5. 경험치가 쌓여 마을 레벨이 오르면 새 건물, 새 주민이 열린다

- 생산은 건물마다 **최대 12시간 분량**까지 쌓이고, 그 뒤로는 수확할 때까지 멈춤
- 건설·업그레이드는 레벨에 따라 10초~몇 시간. 동시에 지을 수 있는 수는 2개(마을 회관 업그레이드로 3개)
- 시간 단축 아이템·결제 없음

## 4. 자원과 재화
| 자원 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 쌀 | 논 | 주민 부탁, 떡 만들기, 건설 |
| 나무 | 벌목장 | 건설·업그레이드 |
| 돌 | 채석장 | 건설·업그레이드 (중반 이후) |
| 떡 | 방앗간 (쌀을 가공) | 주민 부탁, 잔치 |
| 엽전 | 장터(자원 판매), 부탁 보상 | 장식물, 길, 일반 건물 건설·업그레이드 보조 |
| **시아코인** | SIA-WORLD 공통 재화. 어느 게임이든 한 판 할 때마다 1코인 | **땅 확장, 특별 건물 구매** |

- 쌀·나무·돌·떡은 창고 용량 제한이 있음
- 엽전은 시아마을 전용 지갑 (다른 게임의 엽전과 공유하지 않음)
- 시아코인은 공통 지갑에서 잔액을 읽고, 구매할 때 차감만 함. 시아마을 안에서는 벌 수 없음
- 시아코인이 없어도 마을 레벨은 끝까지 올릴 수 있어야 함

## 5. 건물
| 건물 | 역할 | 열리는 마을 레벨 | 짓는 재화 |
|---|---|---|---|
| 마을 회관 | 마을의 중심. 업그레이드하면 건물 최대 레벨과 건설 슬롯 증가 | 1 | 일반 자원 |
| 논 | 쌀 생산 | 1 | 일반 자원 |
| 주민 집 | 주민 1명이 살 집. 지어야 주민이 이사 옴 | 1 | 일반 자원 |
| 벌목장 | 나무 생산 | 2 | 일반 자원 |
| 창고 | 자원 보관 용량 증가 | 2 | 일반 자원 |
| 장터 | 자원을 엽전으로 판매. 하루에 한 번 시세가 바뀜 | 3 | 일반 자원 |
| 채석장 | 돌 생산 | 4 | 일반 자원 |
| 방앗간 | 쌀 → 떡 가공 | 5 | 일반 자원 |
| 장독대 | 떡·쌀을 오래 묵혀 더 비싼 특산품으로 | 8 | 일반 자원 |
| **정자** (특별) | 주변 건물 생산량 소폭 증가 | 6 | 시아코인 20 |
| **잔치 마당** (특별) | 떡을 모아 잔치를 열면 하루 동안 마을 전체 생산량 증가 | 10 | 시아코인 40 |
| **십이지 사당** (특별) | 마을의 상징. 주민 친밀도가 더 빨리 오르고 번영도가 크게 오름 | 14 | 시아코인 60 |
| 장식물 | 나무, 꽃밭, 돌담, 장승, 등불, 연못 등. 번영도를 올림 | 1~ | 엽전 |
| 길 | 건물 사이를 잇는 꾸미기용 길 | 1 | 엽전 |

- 생산·기능 건물은 최대 10레벨까지 업그레이드 (생산량·용량 증가, 모습은 3단계로 바뀜)
- 특별 건물은 각각 하나씩만. 구매 후 업그레이드는 일반 자원으로
- 건물은 언제든 자리를 옮길 수 있음 (비용 없음)
- 같은 생산 건물은 마을 레벨에 따라 지을 수 있는 개수 제한

## 6. 땅과 마을 레벨
- 마을은 격자 칸. 처음 8×8칸, **시아코인**으로 6단계 확장 (마을 레벨 조건도 함께 필요)

| 확장 | 크기 | 가격 |
|---|---|---|
| 1단계 | 10×10 | 10코인 |
| 2단계 | 12×12 | 20코인 |
| 3단계 | 14×14 | 30코인 |
| 4단계 | 16×16 | 50코인 |
| 5단계 | 18×18 | 70코인 |
| 6단계 | 20×20 | 100코인 |

- 마을 레벨은 최대 30. 건설, 업그레이드, 수확, 부탁 완료로 경험치 획득
- 목표 속도: 첫날 레벨 5, 일주일에 레벨 12 안팎, 레벨 30까지 약 두 달

## 7. 주민 (십이지)
- 마을 레벨이 오르고 빈 주민 집이 있으면 십이지가 순서대로 한 명씩 이사 옴
- 주민을 건물에 배치하면 그 건물에 보너스
- 주민마다 친밀도(최대 5단계). 부탁을 들어주면 오르고, 단계가 오르면 보너스 증가와 전용 장식물 선물

| 주민 | 잘하는 일 | 이사 오는 마을 레벨 |
|---|---|---|
| 쥐 | 창고 용량 증가 | 1 |
| 소 | 논 생산량 증가 | 2 |
| 호랑이 | 벌목장 생산량 증가 | 3 |
| 토끼 | 방앗간 가공 속도 증가 | 5 |
| 용 | 마을 회관: 건설 시간 단축 | 7 |
| 뱀 | 장독대 숙성 속도 증가 | 9 |
| 말 | 장터: 하루 판매 한도 증가 | 11 |
| 양 | 정자: 주변 보너스 범위 증가 | 13 |
| 원숭이 | 채석장 생산량 증가 | 15 |
| 닭 | 아침 첫 수확 보너스 | 18 |
| 개 | 최대 누적 시간 12시간 → 15시간 | 21 |
| 돼지 | 장터 판매 가격 증가 | 24 |

## 8. 부탁
- 주민 부탁: "쌀 30개만 구해 줘" 같은 부탁. 들어주면 엽전·경험치·친밀도. 한 번에 3개까지, 완료하거나 넘기면 일정 시간 뒤 새 부탁
- 오늘의 할 일: 하루 3개(예: 수확 10번, 건물 1개 업그레이드). 모두 끝내면 추가 보상
- 마을 목표: 마을 레벨마다 길잡이 역할의 목표(예: "벌목장을 지어 보세요"). 따로 튜토리얼 없이 이것으로 안내

## 9. SIA-WORLD 연결
다른 게임과의 연결은 두 가지야.
1. **시아코인**: 한 판당 1코인 → 땅 확장·특별 건물
2. **기념물**: 다른 게임에서 성과를 내면 마을에 세울 수 있는 특별 장식물(번영도가 높음)이 열림

| 게임 | 조건 (예시) | 기념물 |
|---|---|---|
| 시아탱크 | 첫 승리 / 10승 | 낡은 대포 / 황금 대포 |
| 시아배구 | 첫 승리 / 10승 | 배구 네트 / 우승 깃발 |
| 시아런닝 | 완주 / 개인 최고 기록 갱신 | 출발선 깃발 / 결승선 아치 |
| 시아서바이벌 | 맵 클리어 (4개 맵 각각) | 도깨비 석상 / 구미호 석상 / 이무기 석상 / 염라 석상 |
| 시아디펜스 | 지역 3·6·9·12 클리어 | 망루 / 성문 / 누각 / 십이지 탑 |
| 시아맞고·시아카지노 | 첫 승리 | 화투 평상 / 행운의 분수 |

- 각 게임의 전용 재화(엽전 등)는 주고받지 않음
- 기념물 조건은 각 게임의 기존 기록 테이블을 읽어서 확인. 게임 쪽 코드는 가능한 한 건드리지 않음
- 아직 저장소에 없는 게임의 기념물은 데이터만 준비해 두고, 그 게임이 생기면 켤 수 있게

## 10. 다른 마을 구경
- 랭킹에서 다른 사람 마을을 눌러 구경 (읽기 전용)
- 칭찬 남기기: 하루 5번. 받은 사람은 번영도가 조금 오르고, 준 사람도 엽전을 조금 받음. 같은 마을에는 하루 한 번
- 자원 선물·교환·채팅 없음

## 11. 랭킹
- 번영도 랭킹: 번영도 = 건물 레벨 합 + 장식물 점수 + 기념물 점수 + 주민 친밀도 + 받은 칭찬
- 번영도가 높은 순 → 같으면 먼저 달성한 순. 누적 운영(초기화 없음)
- 표시: 순위, 아이디, 마을 이름, 마을 레벨, 번영도, [구경] 버튼. 내 순위는 항상 표시
- 상위 순위 아이콘은 다른 SIA-WORLD 랭킹과 통일

## 12. 조작
| 동작 | 방법 |
|---|---|
| 마을 이동 | 끌기 (PC: 마우스 드래그) |
| 확대/축소 | 두 손가락 벌리기 (PC: 휠) |
| 수확 | 건물 위 아이콘 누르기. 손가락을 끌면 지나가는 건물을 한꺼번에 수확 |
| 짓기 | [짓기] → 건물 선택 → 놓을 칸 선택 → 확인 |
| 건물 관리 | 건물 누르기 → [업그레이드] [주민 배치] [옮기기] [보관] |

## 13. 데이터 (Supabase, 기존 규칙에 맞춰 이름과 RLS 조정)
- `village_profiles`: user_id, village_name, level, exp, resources(JSON), land_stage, prosperity, praise_count, last_seen_at, updated_at
- `village_buildings`: id, user_id, type, level, x, y, state(건설 중/완료), finish_at, last_collected_at, assigned_resident
- `village_residents`: user_id, resident, affinity, moved_in_at
- `village_requests`: id, user_id, kind(주민/오늘/목표), content(JSON), progress, expires_at
- `village_monuments`: user_id, monument_id, unlocked_at, placed
- `village_praises`: from_user_id, to_user_id, date
- 수확·건설·업그레이드·판매·시아코인 차감처럼 자원이 바뀌는 동작은 모두 **Supabase 함수(RPC)에서 서버 시간으로 계산**해 조작을 막아 줘. 시아코인은 잔액 부족 시 거절
- 다른 사람 마을은 읽기 전용으로 조회

## 14. 디자인과 사운드 (DESIGN.md 기준)
- UI 스타일과 사운드 규칙은 DESIGN.md를 그대로 따름
- 분위기: 평화로운 한국 전통 마을. 기와집·초가집, 논, 장독대, 정자, 돌담
- 실제 시간에 맞춰 낮·저녁·밤 색감이 바뀜 (밤에는 등불이 켜짐)
- 그림이 아직 없으면 임시 도형으로 먼저 만들고, 필요한 에셋 목록을 따로 정리해 줘 (나중에 SpriteCook으로 제작): 땅 타일, 건물 12종(레벨별 3단계 모습), 장식물 20종 안팎, 기념물, 십이지 주민 걷기·일하기 동작, 자원 아이콘, 메뉴 UI
- 사운드: 잔잔한 마을 BGM(낮/밤), 수확음, 건설 시작·완료음, 레벨업, 부탁 완료, 주민 이사 환영음, 버튼음. 소리 켜기/끄기 버튼은 다른 게임과 같은 위치

## 15. 하지 않는 것
결제·유료 재화·광고·돈으로 시간 단축, 다른 마을 공격·약탈·전투, 실시간 멀티플레이·채팅, 유저 간 자원 거래, 게스트 플레이

## 16. 진행 순서
단계마다 직접 실행해서 확인하고, 결과를 보고한 뒤 커밋하고 다음 단계로 넘어가 줘.
1. 마을 화면: 격자 땅, 이동·확대/축소, 건물 짓기·옮기기 (임시 그림)
