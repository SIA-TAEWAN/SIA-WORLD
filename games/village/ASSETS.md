# 시아마을 — 그림·소리 현황과 나중에 만들 것

**9단계에 SpriteCook 으로 만든 것** (Nano Banana 2.1, 투명 배경, 시트 25장 · 300 크레딧. 원본 `art/sheets/`, asset id `spritecook-assets.json`, 만드는 법 `python art/build.py`):
건물 12종 × 모습 3단계, 장식물 12종, 주민 선물 12종, 기념물 16종, 짓는 터 2종 · 길, 자원 아이콘 6종(+ 수확 방울 5종), 땅 바닥 무늬, 로비 카드 `shared/images/card-village.png`.

- 화풍: 굵은 갈색 외곽선 · 밝은 색 · 스티커 느낌 (DESIGN.md), 평화로운 한국 전통 마을(초가집 → 널지붕 → 기와집). 시점은 **정면을 보는 위에서 비스듬한 RPG 시점**(마름모 아이소메트릭이 아님 — 격자가 정사각형이라서). 첫 시험(마름모 시점)은 버렸고, 주민 집 시트(`house2`)를 그다음 그림의 화풍 참고로 썼다.
- 게임은 `public/art/<텍스처 이름>.png` 를 먼저 불러오고(`src/scenes/VillageScene.ts` 의 `preload`, 목록은 `src/scenes/art.ts` 의 `ART_FILES`), 못 불러온 이름만 코드 그림(`makeTextures`)으로 채운다. 짓기 메뉴 · 건물 판 · 보관함의 그림도 같은 텍스처를 쓴다.
- 시트 → 그림: 시트를 칸(가로 3칸 · 3×2 · 2×2)으로 나누고, 옆 칸에서 넘어온 조각과 티끌을 지운 뒤(알파 덩어리), 칸 아래쪽 가운데에 붙인다. 256색 PNG.

## 화면 기준

- 기준 화면 720×1280 (세로). 한 칸 = 장면 좌표 96×96. 가장 당기면(1.8배) 한 칸이 화면에서 약 173px 이라 그림은 **칸의 2배**로 만든다.
- 건물 그림: 가로 `칸 수 × 96`, 세로 `칸 수 × 96 + 40 × 가로 칸 수` 의 2배. 1×1 = **192×272**, 2×2(마을 회관 · 정자 · 잔치 마당 · 사당) = **384×544**. 칸의 아래 변 = 건물 바닥.
- 모습 3단계: 레벨 1~3 → 1, 4~7 → 2, 8~10 → 3 (`lookOf`). 레벨은 오른쪽 아래 작은 동그라미(코드).

## 7. 낮 · 저녁 · 밤

- 서버 시각을 한국 시간으로 보고(`src/scenes/sky.ts`), 마을 위에 곱하기로 색을 덮는다: 낮(7~17시) 없음 · 저녁(17~19시, 새벽 5~7시) 노을빛 · 밤(20~5시) 남색. 시간 사이는 부드럽게 바뀐다.
- 밤에는 등불 빛(`glow`, 코드로 그린 노란 동그라미, 더하기)이 켜진다: 등불 · 사당 · 잔치 마당 · 정자(모습 2부터) · 주민 집과 마을 회관(모습 3).
- 테스트 모드: `?hour=22` 로 시각을 정한다.

## 8. 소리

공용 효과음(`shared/sound.js`)의 이름은 그대로 빌려 쓰고(`click` `toggle` `chip` `coin` `win` `fold`), 마을 전용 소리는 `src/ui/vsound.ts` 가 코드로 만든다 (공용 파일은 고치지 않는다). `shared/sounds/<이름>.ogg|.mp3` 를 넣으면 그 파일로 바뀐다.

| 상황 | 이름 |
|---|---|
| 수확 | `villHarvest` (방울 하나하나는 `chip`) |
| 건설 · 업그레이드 · 가공 시작 | `villBuild` |
| 건설 · 업그레이드 끝 | `villDone` |
| 레벨업 | `villLevel` |
| 부탁 · 마을 목표 완료 | `villRequest` |
| 주민 이사 환영 | `villWelcome` |
| 배경음 낮 / 밤 | `bgmVillDay` / `bgmVillNight` (`src/ui/music.ts`, 코드로 만든 5음 음계 반복곡. 하늘 색과 같은 때에 바뀐다) |

소리 버튼은 오른쪽 아래 원형 버튼(다른 게임과 같은 자리). 효과음 설정(`sia:sound`)을 따르고, 배경음은 효과음이 켜져 있고 공용 배경음 설정(`sia:bgm`)도 켜져 있을 때 울린다.
