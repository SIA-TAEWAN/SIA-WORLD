# 시아마을 — 그림·소리 현황과 나중에 만들 것

지금(1~3단계)은 모두 **코드로 그린 임시 그림**이다 (DESIGN.md 색·외곽선 규칙).
- 마을의 땅·건물·수확 방울·짓는 터·땅 밖 나무: Phaser 그래픽으로 텍스처를 만든다 (`src/scenes/art.ts`). 색은 `shared/theme.js` 의 값만 쓴다.
- 자원·시아코인·경험치·시간 아이콘: 코드로 그린 SVG (`src/ui/icons.ts`, 색은 `shared/theme.css` 변수).
- 길잡이 캐릭터(마을 목표·레벨업 창)는 공용 십이지 그림 `shared/images/zodiac/face/rat.png` · `full/rat.png` (찍찍이).
- 아래 메뉴의 아이콘은 그림 글자(🔨 🐭 📜 🗿 🏆)다.

정식 그림은 9단계에서 SpriteCook 으로 만들어 아래 **파일 이름**으로 `games/village/public/art/` 에 넣는다.
`src/scenes/art.ts` 의 `makeTextures` 가 같은 이름의 텍스처를 그림 파일로 먼저 채우게 하면 되고(못 불러오면 코드 그림), 건물 관리 판·짓기 메뉴의 그림은 그 텍스처를 그대로 쓰므로 함께 바뀐다.
원본 시트와 asset id 는 `games/village/art/`, `games/village/spritecook-assets.json` 에 남긴다 (시아서바이벌과 같은 방식).

스타일: 굵은 갈색 외곽선(`#2A1A10`), 밝은 단색, 흐린 그림자 없음, 장난감·스티커 느낌 (DESIGN.md). 분위기는 평화로운 한국 전통 마을 — 기와집·초가집, 논, 장독대, 정자, 돌담 (PRD 14장). 배경은 투명.

## 화면 기준

- 기준 화면 720×1280 (세로). 마을은 위에서 비스듬히 내려다본 **정면 그림**을 정사각 칸에 세운다 (지금 코드 그림과 같은 구도: 칸의 아래쪽 변에 건물 바닥을 맞추고, 지붕이 위 칸으로 솟는다).
- 한 칸 = 장면 좌표 96×96. 가장 가까이 당기면(1.8배) 한 칸이 화면에서 약 173px 이므로 그림은 **칸의 2배 크기**로 만든다.
- 건물 그림의 크기: 가로 `칸 수 × 96`, 세로 `칸 수 × 96 + 40 × 가로 칸 수` (위로 솟는 부분). 1×1 건물 = 96×136 → **192×272** 로 제작, 2×2 건물 = 192×272 → **384×544** 로 제작.
- 건물은 레벨에 따라 모습이 3단계로 바뀐다 (`lookOf`: 레벨 1~3 → 1, 4~7 → 2, 8~10 → 3).

## 1. 땅

| 파일 | 내용 | 지금 | 만들 크기 |
|---|---|---|---|
| `tile-grass-a` `tile-grass-b` | 마을 땅 타일 2종 (체크 무늬로 번갈아 깐다) | 맞고 담요 초록 `#7CC08A` 바탕 + 밝은 칸 `#8FCC9B` | 192×192 |
| `tile-out` | 땅 밖 (아직 넓히지 않은 곳) | 어두운 초록 `#5FA772` 단색 | 192×192 (이어 붙는 무늬) |

## 2. 건물 (PRD 5장: 12종 × 모습 3단계)

이름은 `b-<id>-<모습 1~3>`. **굵은 글씨**가 지금 게임에 들어 있는 다섯 가지 (코드 그림 있음), 나머지는 해당 단계에서 건물을 더할 때 코드 그림을 먼저 넣는다.

| 이름 | 건물 | 칸 | 지금 (코드 그림) | 모습 1 → 2 → 3 |
|---|---|---|---|---|
| **`b-hall-1~3`** | 마을 회관 | 2×2 | 돌 기단 + 크림 벽 + 붉은 기둥 + 잿빛 기와지붕 + 노란 현판 | 단층 기와집 → 2층 누각 → 깃발·금빛 장식 |
| **`b-paddy-1~3`** | 논 | 1×1 | 흙 둑 + 하늘빛 물 + 초록 모 | 모 9포기 → 12포기 → 누렇게 익은 벼 |
| **`b-house-1~3`** | 주민 집 | 1×1 | 크림 벽 + 갈색 문 + 지붕 | 초가집 → 널지붕 집(창문) → 기와집(등불) |
| **`b-lumber-1~3`** | 벌목장 | 1×1 | 그루터기·도끼 + 통나무 더미 | 통나무 3개 → 지붕 달린 작업대·통나무 6개 → 기와지붕 |
| **`b-storage-1~3`** | 창고 | 1×1 | 크림 벽 + X자 나무 문 + 지붕 | 초가 곳간 → 널지붕 → 기와 곳간(금빛 문양) |
| `b-market-1~3` | 장터 | 1×1 또는 2×1 | (4단계) | 좌판 → 천막 가게 → 기와 상점 |
| `b-quarry-1~3` | 채석장 | 1×1 | (4단계) | 돌무더기·곡괭이 → 수레 → 석공 작업대 |
| `b-mill-1~3` | 방앗간 | 1×1 | (4단계) | 절구 → 디딜방아 → 물레방아 |
| `b-jar-1~3` | 장독대 | 1×1 | (4단계) | 장독 3개 → 6개 → 지붕 있는 장독대 |
| `b-pavilion-1~3` | 정자 (특별) | 2×2 | (5단계) | 사방이 트인 정자 |
| `b-feast-1~3` | 잔치 마당 (특별) | 2×2 | (5단계) | 멍석·상 → 차양 → 청사초롱 |
| `b-shrine-1~3` | 십이지 사당 (특별) | 2×2 | (5단계) | 작은 사당 → 단청 → 십이지 석상 |
| **`site-1` `site-2`** | 짓는 중인 터 (1×1 · 2×2) | 주황 흙바닥 + 나무 틀 | — |
| `fx-upgrade` | 업그레이드 중 표시 (건물 위에 덮는 비계, 선택) | 없음 (진행 막대만) | 1×1 · 2×2 |

## 5. 주민 (6단계)

- 지금은 주민이 없다. 구조만: 주민 id 는 `shared/zodiac.js` 의 십이지 id (rat … pig), 건물의 `resident` 칸(서버 `assigned_resident`)에 들어간다.
- 임시: `shared/images/zodiac/full/<id>.png` 한 장을 코드로 움직인다 (다른 게임과 같은 방식: 통통 걷기 · 좌우 뒤집기).

| 파일 | 내용 | 크기 |
|---|---|---|
| `res-<id>-walk.png` × 12 | 걷기 4프레임 가로 시트 (오른쪽 보기) | 프레임 128×128 |

## 7. 낮 · 저녁 · 밤 (9단계)

실제 시간에 맞춘 색감 변화는 그림이 아니라 화면 전체에 덧씌우는 색(CSS 또는 카메라 색조)으로 한다. 밤에 켜지는 **등불 빛**(`fx-lantern`, 노란 동그란 빛 128×128)만 따로 만든다.

## 8. 소리

지금은 SIA WORLD 공용 효과음(`shared/sound.js`)의 **이미 있는 이름**만 빌려 쓴다 (`shared/` 는 10단계 전에는 고치지 않는다).

| 상황 | 지금 쓰는 이름 | 9단계에서 더할 이름 |
|---|---|---|
| 버튼 | `click` · `toggle` | 그대로 |
| 수확 방울 누르기 / 자원이 들어옴 | `chip` / `coin` | `villHarvest` |
| 건설 시작 · 완성 · 업그레이드 | `tankBuild` | `villBuild` `villDone` |
| 옮기기 | `chip` | `villPlace` |
| 레벨업 | `survLevel` | `villLevel` |
| 마을 목표 보상 | `win` | `villGoal` (부탁 완료와 함께) |
| 거절 (자원 부족 등) | `fold` | 그대로 |
| 주민 이사 환영 | — | `villWelcome` (6단계) |
| 배경음 | 없음 | `bgmVillDay` `bgmVillNight` (잔잔한 마을 곡, 코드로 만든 반복곡 + 파일이 있으면 교체) |

소리 켜기/끄기 버튼은 오른쪽 아래 원형 버튼(다른 게임과 같은 자리, 아래 메뉴 바로 위)이고 설정은 공용 값(`sia:sound`)을 쓴다.
