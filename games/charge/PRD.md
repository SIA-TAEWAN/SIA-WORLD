# 시아돌격대 PRD (요약)

전체 PRD는 claude.ai 의 "시아돌격대 PRD" 문서. 여기에는 구현에 필요한 결정 사항과 진행 상황만 적는다.

## 결정 사항

- 1인 전용 무리 달리기 게임. 십이지 돌격대가 자동으로 앞으로 달리고, 플레이어는 **좌우 드래그**로만 움직인다.
- 길 위의 **숫자 문**(+N · ×N · −N · ÷N) 중 하나를 골라 통과하면 대원 수가 바뀐다. **문에 총을 쏘면 + 와 − 문의 숫자가 오른다** (−는 0을 지나 +가 된다).
- 대원은 앞으로 자동 사격해 요괴 무리를 쓰러뜨린다. 남은 요괴와 부딪히면 서로 한 명씩 사라진다 (방망이 도깨비는 한 마리가 대원 3명).
- 길 끝의 보스(1~4번째: 작은 대장 요괴, 5번째: 지역 보스) 앞에서 멈춰 싸운다. 보스 공격은 빨갛게 예고되고, 비켜 서면 피한다.
- 구성: 십이지 12지역 × 5스테이지 = 60스테이지 + 끝없는 모드. 한 스테이지 약 1분.
- 대장 12종(처음 쥐·소·호랑이 3종), 차이는 10% 안팎.
- 13번째 대장 고양이(076): 수치 대신 "아홉 목숨" — 모두 쓰러지면 한 번, 이번 판 최대 대원의 15%(최소 9명)로 다시 일어난다. 지역으로 열리지 않고 로비에서 시아코인으로 연다 (`progress.ts` 의 `extraOpen`, 서버는 `_check_character`).
- 별: 클리어 1개, 남은 대원이 기준 이상이면 2·3개. 랭킹 2가지(스테이지 = 별 개수, 끝없는 모드 = 달린 거리).
- 엽전은 시아돌격대 전용 지갑, 한 판마다 시아코인 1.
- 화면에는 대원을 최대 300명만 그리고 나머지는 숫자로 보여 준다.

## 수치 (구현 기준)

- 길 폭 560 · 전진 300/초 · 좌우 1100/초 · 최대 대원 9999 · 화면에 그리는 대원 300
- 화력 `10 × 대원^0.7` · 사거리 720 · 문 피해 45마다 숫자 1 (최대 99)
- 별 기준: 스테이지마다 [자동 조종이 보스에 도착할 때 대원의 35%, 70%] (`npm run calib` 가 `src/data/calib.ts` 를 만든다)
- 지역 열기: 앞 지역 5번째 스테이지 클리어 + 모은 별 `(지역-1) × 9`
- 엽전: 클리어 `15 + 5×지역 + 5×별`, 첫 클리어 `20 + 10×지역`, 실패 `클리어(별 0)의 30% × 간 거리`, 끝없는 길 `거리(m)/20 + 보스 5`, 상자 엽전 더함 → 강화 `엽전` 배율 · 돼지 대장 ×1.1
- 강화 6종: 시작 대원 · 공격력 · 연사 속도 · 사거리 · 보스 피해 · 엽전 획득 (가격 `기본 + 단계 × 증가`)
- 시아코인: 20초 이상 달린 판마다 1 (`_grant_sia_coin(user, 'charge', run)`)

## 구조

- `src/data/balance.ts` 수치 · 요괴 9종 · 보스 12종 · 장애물 · 대장 12종
- `src/data/growth.ts` 강화 · 지역 · 엽전 식, `src/data/stages.ts` 60스테이지 (1지역은 손으로, 2~12지역은 시드로 만든다) · 끝없는 길 구간
- `src/game/sim.ts` 판 시뮬레이션 (순수 함수, 고정 간격 1/60초, 무작위 없음)
- `src/game/autopilot.ts` 자동 조종 (테스트·보정의 "생각하는 플레이어", 개발용 `?auto=1`)
- `src/game/progress.ts` 판 밖 규칙 (서버 `061_charge.sql` 과 같은 규칙, `tests/sql.test.ts` 가 표와 식을 비교)
- `src/net/api.ts` 서버 RPC (`charge_profile` · `charge_start` · `charge_finish` · `charge_buy_upgrade`), 못 보낸 결과는 기기에 5개까지 보관했다가 다시 보낸다
- `src/scenes/GameScene.ts` Phaser 화면 (시뮬레이션 상태를 그리기만 한다)
- `src/ui/app.ts` 메인 · 십이지 지도 · 스테이지 · 강화 · HUD · 일시정지 · 결과

개발: `npm run dev` → `http://localhost:5295/games/charge/?local=1` (로그인 없이 기기에만 저장). `&stage=7-3` 바로 시작, `&speed=4` 배속, `&auto=1` 자동 조종, `&all=1` 모든 스테이지·대장 열기(기록 안 함).
