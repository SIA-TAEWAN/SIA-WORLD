## 전용 그림 만들기 (SpriteCook) — 작업 지시

**완료 (2026-11-20)** — 아래 9장을 만들어 넣었다. 다시 만들 때도 이 순서를 따른다 (로비 카드는 `art/card.png` 로 두면 build.py 가 함께 만든다).

**순서**
1. `get_credit_balance` 로 크레딧 확인 (아래 9장 · 모델 `gemini-3.1-flash-image`, `smart_crop_mode="tightest"`, 배경 투명).
2. 모든 그림에 `style_asset_ids` 로 화풍 참고를 넣는다:
   `b1e84f6b-3e8b-4943-bd28-9993fa4eda7e`(꼬마 도깨비) · `57323464-7f94-4d37-bf78-d2dbde2a455e`(표창) · `12011533-d60f-496a-ba2e-814c7796d093`(들판 바닥). 메인 그림만 `878c43af-234d-4b5b-8fb8-ad39ba6fe076`(시아디펜스 메인)도 더한다.
3. 받은 그림을 `games/charge/art/<이름>.png` 로 저장하고, `spritecook-assets.json` 에 `{asset_id, label: "<이름> → …"}` 를 적는다 (label 은 이름으로 시작).
4. `python art/build.py` → `public/art/<이름>.png` 가 생기고 sha12 가 적힌다.
5. `src/scenes/art.ts` 의 `ART_FILES` 에 만든 이름을 적는다 → 게임이 그 그림을 쓴다 (없는 것은 지금 코드 그림 그대로).
6. `npm test` · `npm run build`, `?local=1&all=1&auto=1&stage=1-4` (통나무·상자) · `stage=3-2` (물웅덩이) · `stage=4-2` (흙더미) 로 화면 확인.

공통 화풍: 굵은 갈색 외곽선(#2A1A10), 밝은 단색, 흐린 그림자 없음, 장난감·스티커 느낌, 귀엽게, 배경 투명, 글자 넣지 않기.
