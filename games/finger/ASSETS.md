### 코드로 그리는 것 (7단계)

- **방:** 굵은 갈색 외곽선 + 나무 띠 + 밝은 줄 + 모서리 노란 못, 바닥 위쪽 옅은 그늘. 방이 바뀔 때만 다시 그린다 (`GameScene.drawRoom`).
- **장애물:** 네모 돌기둥(어두운 옆면 + 밝은 윗면 + 이음매) · 둥근 돌기둥 · 가시밭(초록 덤불 + 크림색 가시) · 빨래판(나무 틀 + 골) · 순간이동 구멍(짝마다 파랑/분홍, 소용돌이 그림 하나를 돌린다).
- **효과 (`src/scenes/fx.ts`):** 판을 열 때 흰 그림 16장(`g-*`: 점 · 원 · 고리 · 별 · 십자 · 방패 · 이빨 · 구슬 · 물방울 · 방울 · 바위 · 화살표 · 느낌표 · 방사형 빛 · 소용돌이 · 4px 점)을 한 번 만들어 물들여 쓴다.
  - 우정 콤보: 표창(표창이 날아가며 흰 궤적) · 땅 울림(주황 원 + 고리 두 겹 + 돌 조각, 약한 흔들림) · 가로 레이저(분홍) / 세로 레이저(파랑) · 회복 구슬(초록 고리 + 십자) · 독(초록 원 + 방울 6개) · 날려차기(주황 줄 + 별) · 보호막(방패가 떠오름) · 튕김 구슬(구슬이 차례로 날아감) · 효과 지우기(흰 고리 + 별) · 따라가는 이빨(위아래 이빨이 두 번 묾) · 엽전(엽전 3개가 떠오름)
  - 타격 숫자(약점은 분홍으로 크게 + 별 + '약점!') · 요괴가 맞으면 잠깐 하얗게·커짐·흔들림 · 쓰러지면 하얗게 번쩍이며 돌면서 작아짐(보스는 별·고리·약한 흔들림)
  - 큰 공격 예고: 깜빡이는 빨간 원 + 두 겹 테두리 + 도는 흰 점선 + 느낌표 + 요괴와 잇는 점선, 새로 보일 때 '큰 공격 예고!'
  - 상태 아이콘: 요괴 방패·숨음·독·단단함(오른쪽 위), 대원 독·느려짐·약해짐(머리 위)
  - 웨이브 띠 글자('웨이브 2' · '마지막 웨이브!' · 'N층 · 보스!') · 클리어(큰 글자 + 별·색종이) · 실패(방이 어두워지고 빨간 글자)
  - 필살기 컷인(0.75초): 기울어진 타입 색 띠 + 방사형 노란 빛 + 얼굴 + 필살기 이름. 그동안 발사를 멈췄다가 컷인 뒤에 필살기 효과를 보여 준다.
- **가볍게:** 떠 있는 효과 조각은 48개까지(`MAX_FX`), 떠오르는 글자는 14개를 돌려 쓰고, 바닥 TileSprite 는 반 크기로 만들어 2배로 늘인다. 화면 흔들림 세기는 0.006 까지.

## 소리 · 진동

공용 `shared/sound.js` 의 효과음만 쓴다 (고친 것 없음 — `play(name, { rate, volume })` 의 `rate` 로 높낮이를 바꾼다). 아이폰 소리 깨우기와 켜기/끄기 저장(`sia:sound`)도 공용 모듈이 한다. 소리 버튼은 판 밖 화면 오른쪽 아래, 판 안에서는 일시정지 창.

| 때 | 소리 |

| 발사 | `volleyServe` (세게 당길수록 높게) |

## 전용 그림 자리 (SpriteCook) — 작업 지시

**아직 만든 그림이 없다.** 자리는 준비되어 있어, 파일을 넣고 목록에 이름만 적으면 게임이 그 그림을 쓴다 (시아돌격대 `ART_FILES` 와 같은 방식).

**넣는 순서**
1. `get_credit_balance` 로 크레딧 확인. 모델 `gemini-3.1-flash-image`, `smart_crop_mode="tightest"`, 배경 투명(바닥·메인 그림은 배경 포함).
2. 화풍 참고 `style_asset_ids`: `b1e84f6b-3e8b-4943-bd28-9993fa4eda7e`(꼬마 도깨비) · `57323464-7f94-4d37-bf78-d2dbde2a455e`(표창) · `12011533-d60f-496a-ba2e-814c7796d093`(들판 바닥). 대원 그림은 그 대원의 십이지 그림(`shared/images/spritecook-assets.json`)을 `reference_asset_id` 로.
3. 받은 그림을 아래 표의 크기로 맞춰 `public/art/<이름>.png` 로 저장하고 (돌격대 `art/build.py` 를 가져다 써도 된다), `spritecook-assets.json` 의 `assets` 에 `{asset_id, sha12, label: "<이름> → public/art/<이름>.png (크기)"}` 를 적는다.
4. **`src/artlist.ts` 의 `ART_FILES` 에 이름을 적는다.** 적지 않은 이름은 아예 받지 않으므로 404·콘솔 오류가 없다. 적었는데 못 읽으면 지금의 코드 그림·있는 그림으로 그린다. `tests/feel.test.ts` 가 적은 이름마다 파일과 asset id 가 있는지 확인한다.
5. `npm test` · `npm run build`, `?local=1&all=1&auto=1&stage=12-5` (장애물 4종) · `stage=9-3` (둥근 기둥) 로 확인.
