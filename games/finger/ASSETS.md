### 코드로 그리는 것 (7단계 — 지금은 전용 그림을 못 읽었을 때의 대체 그림)

- **방:** 굵은 갈색 외곽선 + 나무 띠 + 밝은 줄 + 모서리 노란 못, 바닥 위쪽 옅은 그늘. 방이 바뀔 때만 다시 그린다 (`GameScene.drawRoom`).
- **장애물:** 네모 돌기둥(어두운 옆면 + 밝은 윗면 + 이음매) · 둥근 돌기둥 · 가시밭(초록 덤불 + 크림색 가시) · 빨래판(나무 틀 + 골) · 순간이동 구멍(짝마다 파랑/분홍, 소용돌이 그림 하나를 돌린다).
- **효과 (`src/scenes/fx.ts`):** 판을 열 때 흰 그림 16장(`g-*`: 점 · 원 · 고리 · 별 · 십자 · 방패 · 이빨 · 구슬 · 물방울 · 방울 · 바위 · 화살표 · 느낌표 · 방사형 빛 · 소용돌이 · 4px 점)을 한 번 만들어 물들여 쓴다.
  - 우정 콤보: 표창(표창이 날아가며 흰 궤적) · 땅 울림(주황 원 + 고리 두 겹 + 돌 조각, 약한 흔들림) · 가로 레이저(분홍) / 세로 레이저(파랑) · 회복 구슬(초록 고리 + 십자) · 독(초록 원 + 방울 6개) · 날려차기(주황 줄 + 별) · 보호막(방패가 떠오름) · 튕김 구슬(구슬이 차례로 날아감) · 효과 지우기(흰 고리 + 별) · 따라가는 이빨(위아래 이빨이 두 번 묾) · 엽전(엽전 3개가 떠오름)
  - 타격 숫자(약점은 분홍으로 크게 + 별 + '약점!') · 요괴가 맞으면 잠깐 하얗게·커짐·흔들림 · 쓰러지면 하얗게 번쩍이며 돌면서 작아짐(보스는 별·고리·약한 흔들림)
  - 큰 공격 예고: 깜빡이는 빨간 원 + 두 겹 테두리 + 도는 흰 점선 + 느낌표 + 요괴와 잇는 점선, 새로 보일 때 '큰 공격 예고!'
  - 상태 아이콘: 요괴 방패·숨음·독·단단함(오른쪽 위), 대원 독·느려짐·약해짐(머리 위)
  - 웨이브 띠 글자('웨이브 2' · '마지막 웨이브!' · 'N층 · 보스!') · 클리어(큰 글자 + 별·색종이) · 실패(방이 어두워지고 빨간 글자)
  - 필살기 컷인(0.75초): 기울어진 타입 색 띠 + 방사형 노란 빛 + 얼굴 + 필살기 이름. 그동안 발사를 멈췄다가 컷인 뒤에 필살기 효과를 보여 준다.
- **가볍게:** 떠 있는 효과 조각은 48개까지(`MAX_FX`), 떠오르는 글자는 14개를 돌려 쓰고, 바닥 TileSprite 는 반 크기로 만들어 2배로 늘인다. 화면 흔들림 세기는 0.006 까지.

## 전용 그림 (SpriteCook)

넣은 그림은 `src/artlist.ts` 의 `ART_FILES` 에 적혀 있다. 적은 이름만 받고, 판은 그 판에 쓰는 것만 받는다(`artFor`: 데려간 대원의 구슬, 나오는 요괴·보스의 맞는 표정, 쓰는 바닥의 방 테두리, 첫 방의 지역 바닥, 장애물·효과). **판이 열린 뒤에 받는 것**(`GameScene.fetchArt`, Phaser 로더를 다시 돌림): 필살기 컷인은 그 대원 게이지가 2턴(`CUT_AHEAD`) 남았을 때 또는 필살기를 쓸 때 받고, 컷인이 지나가면 텍스처에서 뺀다(다음에 다시 차 가면 브라우저 캐시에서 다시 받음). 아직 못 받았으면 얼굴 그림 컷인. 끝없는 탑은 방의 지역이 바뀔 때 그 지역 바닥을 받고 지나간 바닥은 뺀다(받는 동안은 앞 바닥 그대로), 보스 맞는 표정은 그 보스가 나올 때 받고 쓰러지면 뺀다. 판을 닫으면(씬 SHUTDOWN) 받는 중인 것은 버리고 나중에 받은 텍스처를 뺀다. 메인 그림·화면 배경·메뉴 아이콘은 판 밖 HTML 화면에서만 쓴다. **못 읽으면** 판은 텍스처가 있는지 보고 위의 코드 그림으로, HTML 화면은 단색 배경·이모지·얼굴 그림으로 그린다. `tests/feel.test.ts` 가 적은 이름마다 파일과 asset id(`spritecook-assets.json`), 9칸 그림의 파일 크기를 확인한다.

**만드는 법:** SpriteCook 원본은 저장소에 넣지 않는다(`art/raw/` 는 `.gitignore`). `art/ids.tsv` 의 asset id 로 받아 `art/raw/<이름>.png` 로 두고(`art/get.sh <이름> <asset_id> <url>`) `python art/build.py` 를 돌리면 `public/art/*.png`(256색 팔레트) · `spritecook-assets.json` · 로비 카드 `shared/images/card-finger.png`(640×400) 를 새로 만든다. 십이지 전신 참고 그림 id 는 `art/refs.tsv`. 공통 화풍: 굵은 갈색 외곽선, 밝은 단색, 장난감·스티커 느낌, 글자 없음. 모델 `gemini-3.1-flash-image`, 화풍 참고 `b1e84f6b-…`(꼬마 도깨비) 등.

새 바닥 지역을 더하면 `artlist.ts` 의 `GroundName` 과 build.py 에도 적는다. 맞는 표정 그림은 원래 그림과 크기가 같아야 한다 (같은 배율로 바꿔 끼운다).
