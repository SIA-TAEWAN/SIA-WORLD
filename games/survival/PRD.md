# 시아서바이벌 구현 요청

SIA-WORLD 저장소(SIA-TAEWAN/SIA-WORLD, 로컬 C:\Claude\SIA-WORLD)에 새 게임 **시아서바이벌**을 `games/survival`로 추가해 줘.
십이지 캐릭터 하나로 몰려오는 요괴를 4분 동안 버티는 **1인 전용** 생존 게임이야. 공격은 자동이고 조작은 이동뿐이야.

## 0. 시작 전에 먼저 할 일
코드를 쓰기 전에 아래를 먼저 살펴보고, 무엇을 그대로 가져다 쓸지 짧게 보고해 줘.
- 기존 게임(`games/tank` 등)의 폴더 구조, Phaser 3 설정, 씬 구성
- 통합 로그인(아이디+비밀번호), Supabase 클라이언트 설정, 기존 랭킹 테이블 구조와 랭킹 화면
- DESIGN.md (색, 글꼴, 버튼, 패널, 사운드 규칙)
- 십이지 캐릭터 이미지가 있는 위치와 형식
- SIA-WORLD 게임 선택 화면에 게임을 추가하는 방법
기존 공용 코드와 스타일을 최대한 재사용해 줘.

## 1. 기본 사항
- 기술: Phaser 3, Supabase DB(저장·랭킹), 기존 배포 방식 그대로
- **1인 전용**: 협동·대전·대기방·실시간 통신 없음. 게임 중에는 서버 통신 없이 기기에서만 실행
- 로그인 필수 (게스트 플레이 없음)
- 화면: 세로 9:16, 기준 해상도 720×1280. PC에서는 가운데에 세로 비율로 표시
- 성능: 적 300마리 + 투사체 다수일 때도 모바일 60fps. 적·투사체·구슬·피해 숫자는 모두 오브젝트 풀링
- 한 판: **최대 4분** (4분 모드). 4분에 나오는 최종 보스를 잡으면 클리어. 맵을 4분 모드로 클리어하면 그 맵의 **무한 모드**가 열린다 (3장의 '무한 모드')
- 재화 이름: **엽전**
- 수치(무기·요괴·보스·맵별 등장 표·강화)는 모두 데이터 파일로 분리해 쉽게 조정할 수 있게

## 2. 화면 흐름
로그인 → 게임 선택 → 메인 → 출전 준비 → 게임 → 결과
- 메인: [출전] [강화] [도감] [랭킹], 보유 엽전 표시
- 출전 준비: 캐릭터 선택 → 맵 선택 → 모드 선택(4분 모드 / 헬 모드 / 무한 모드) → 시작 (잠긴 캐릭터·맵·헬·무한 모드는 해금 조건 표시)
- 결과: 생존 시간, 처치 수, 도달 레벨, 얻은 엽전, 새 기록 여부 → [다시하기] [강화하러 가기] [메인으로]

## 3. 게임 진행
- 넓은 필드에서 카메라가 내 캐릭터를 따라다님
- 요괴가 화면 밖 사방에서 나타나 다가옴. 너무 멀어진 요괴는 내 근처로 다시 배치
- 무기는 각자 정해진 간격으로 자동 발사
- 요괴에 닿으면 체력 감소(짧은 무적 시간), 체력 0이면 게임 오버
- **4분이 되면 그 맵의 최종 보스 등장 → 처치하면 클리어, 판 종료**
- 일시정지 가능 (보유 무기·패시브 확인, 포기). 포기·게임 오버여도 주운 엽전은 지급

**시간별 흐름**
| 시간 | 내용 |
|---|---|
| 0~1분 20초 | 약한 요괴 위주, 처음부터 수가 넉넉하고 점점 늘어남 |
| 1분 20초 | 그 맵의 중간 보스 1 |
| 1분 20초~2분 40초 | 빠른 요괴·단단한 요괴·맵 전용 요괴 추가, 떼로 몰려오는 이벤트 |
| 2분 40초 | 그 맵의 중간 보스 2 |
| 2분 40초~4분 | 가장 강한 요괴, 원거리 요괴 |
| 4분 | 그 맵의 최종 보스 → 처치하면 클리어 |

4분 안에 레벨업·무기 진화까지 일어나도록 경험치 곡선과 시간당 성장을 빠르게 잡는다.

**무한 모드** (`data/balance.ts` 의 `ENDLESS`, 서버는 044 · 045)
- 들어가는 곳: 출전 준비에서 맵을 고른 뒤 "4분 모드 / 무한 모드". 그 맵을 4분 모드로 한 번 클리어해야 열린다: 서버의 맵별 최고 기록에 클리어가 있거나, **그 맵의 다음 맵이 열려 있으면** 열린다 (4분제로 바꿀 때 기록을 지워서, 이미 다음 맵을 연 사람도 잠겨 있던 것을 045 에서 풀었다. 마지막 맵 황천길은 클리어 기록만). 4분 모드를 클리어해 무한 모드가 처음 열리면 결과 화면에 알려 준다
- 4분까지는 4분 모드와 완전히 같다. 최종 보스를 잡아도(4분이 지나도) 끝나지 않고 **죽을 때까지** 이어지고, 시계는 계속 올라간다. 클리어는 없다
- 4분 뒤로 m분이 지나면 요괴 체력 ×(1 + 0.25m + 0.06m²) · 피해 ×(1 + 0.15m + 0.03m²) · 등장 수 ×(1 + 0.15m). 끝없이 버틸 수 없다 (강화 49 · 보통 실력으로 평균 6~9분, 가장 긴 판이 10분 30초쯤). 판은 20분(`ENDLESS.maxSec` 1200초)에서 끝나고, 서버도 그보다 긴 생존 시간은 받지 않는다
- 1분 20초마다 그 맵의 보스가 번갈아 다시 나온다 (5:20 중간 보스 1 → 6:40 중간 보스 2 → 8:00 최종 보스 → …). 체력 ×(1 + 0.4m + 0.05m²), 보물상자를 준다. 40초마다 떼 이벤트도 번갈아 다시 온다
- 요괴 수 상한(300)·풀 크기(340)·부활·포기·2배속은 그대로
- 엽전: 한 판에 받는 양에 맵별 상한이 있다 (그 맵 4분 모드 클리어 판 평균의 약 1.5배: 들판 450 · 대나무 숲 400 · 달빛 궁궐 600 · 황천길 560닢). 강화가 빨라지지 않게 서버도 같은 값으로 자른다
- 최종 보스를 잡으면 "끝이 아니에요" 안내를 띄운다 (레벨업 창이 떠 있으면 창이 닫힌 뒤에)
- 시아코인(1분 이상)·누적 처치·떡·도감·누적 조건 해금(용·뱀·양)은 그대로 반영. 시간 조건 해금(토끼·말)·클리어 해금(돼지)·다음 맵 해금은 4분 모드에서만
- 기록·랭킹은 4분 모드와 따로 (10장)

**헬 모드** (`data/balance.ts` 의 `HELL` · `data/maps.ts` 의 `hell` · `data/bosses.ts` 의 `hell`, 서버는 055)
- 기존 맵 4개의 헬 버전 (총 8개). 배경·지형·등장 표·요괴·보스는 같고 더 강하다. 4분 판이고 클리어가 있다 (헬의 무한 모드는 없다)
- 들어가는 곳: 출전 준비에서 맵을 고른 뒤 "4분 모드 / 헬 모드 / 무한 모드". **그 맵을** 4분 모드로 클리어하면 그 맵의 헬 모드가 열린다 (무한 모드와 같은 조건 — 045 의 `_survival_map_cleared`)
- 강함 (체감 약 1.5배): 공통 배율 요괴 체력 ×1.25 · 피해 ×1.2 · 수 ×1.1 · 보스 체력 ×1.5 · 보스 피해 ×1.2 에, 맵마다 조금씩 더 곱한다 (`data/maps.ts` 의 `hell`)
- 보스 12종 각각에 헬 전용 패턴이 하나씩 더 있다 (첫 패턴 바로 뒤에 끼운다). 모두 예고가 보이거나 느린 탄이라 보고 피할 수 있고, 시작할 때 이름을 띄운다. 새 그림 없이 기존 범위 공격·구슬 탄을 쓴다
- 밸런스 ('보통 실력' 정책, `npm run balance -- 60 hell`): 영구 강화 49 에서 클리어율 10~25%, 강화 34 이하에서는 0~5%. 강화 항목은 늘리지 않는다
- 엽전 2배 (서버의 판당 엽전 상한도 2배, `hell_coin_mul`). 시아코인·누적 처치·떡·도감·누적 조건 해금(용·뱀·양)은 4분 모드와 같다. 시간 조건 해금(토끼·말)·클리어 해금(돼지)·다음 맵 해금·누적 최고 생존 시간은 4분 모드에서만
- 화면: 붉고 어두운 색조와 가장자리 불씨·재, "🔥 헬" 배지, 요괴의 붉은 기운, 헬 전용 BGM 변주(맵 곡·보스 곡을 낮고 빠르게), 모드 카드·결과 화면·랭킹의 헬 표시 (DESIGN.md 의 색만 쓴다)
- 기록·랭킹은 4분·무한 모드와 따로 (10장)

**관리자 계정 (시험용, 055)**: `profiles.is_admin` 계정은 시아서바이벌에 들어올 때마다(`survival_profile`) 엽전과 시아코인이 10,000 으로 맞춰진다

**판 안 성장**
- 요괴 처치 → 경험치 구슬 → 가까이 가면 빨려옴
- 레벨업 시 게임이 멈추고 **카드 3장 중 1장 선택**: 새 무기 / 무기 강화 / 새 패시브 / 패시브 강화
- 무기 최대 6개, 패시브 최대 6개, 각각 최대 5레벨
- 진화: 무기 5레벨 + 짝 패시브 보유 시, 보스가 떨구는 보물상자에서 진화 무기 획득
- 카드 가중치: 진화가 카드 운에만 달리지 않게, **이미 가진 무기의 강화 카드는 2배**(진화가 있는 무기는 **3배**), **가진 무기의 진화 짝 패시브(아직 없을 때)는 4배** 자주 나온다 (나머지 카드는 1배. `data/balance.ts` 의 `CARD_WEIGHT`)

**필드 아이템**: 경험치 구슬(작음·중간·큼), 엽전, 떡(체력 회복), 복주머니(구슬 모두 끌어당김), 부적(화면의 일반 요괴 모두 처치), 보물상자(보스 드롭)

## 4. 캐릭터

## 6. 맵, 요괴, 보스
맵 4종. 처음에는 1번만 열려 있고 앞 맵을 클리어(4분 모드에서 최종 보스 처치)하면 다음 맵 해금.
맵마다 요괴 구성, 전용 요괴, 보스 3종이 모두 달라.

| 맵 | 느낌 | 난이도 | 엽전 배율 | 요괴 강함(체력·속도·수) | 나오는 요괴 |
|---|---|---|---|---|---|
| 1. 들판 | 넓은 풀밭, 장애물 적음 | 쉬움 | ×1.0 | ×1.0 | 꼬마 도깨비·도깨비불·방망이 도깨비 위주, 물귀신·여우불은 후반에 조금 |
| 2. 대나무 숲 | 대나무가 길을 막음 | 보통 | ×1.5 | 약 ×1.3 | 도깨비불·물귀신·여우불 + 죽순 요괴. 빠른 요괴와 원거리 요괴가 일찍 나옴 |
| 3. 달빛 궁궐 | 밤 분위기, 길이 좁음 | 어려움 | ×2.0 | 약 ×1.6 | 전 종류 + 수문장 요괴. 떼로 몰려오는 이벤트가 잦음 |
| 4. 황천길 | 저승으로 가는 어두운 길, 안개와 푸른 불빛, 군데군데 삼도천 물길 | 매우 어려움 | ×2.5 | 약 ×2.0 | 해골 병사·원혼·도깨비불·물귀신·여우불. 처음부터 수가 많고 원거리 요괴가 일찍 나옴 |

**공통 요괴** (등장 시간은 들판 기준)
| 종류 | 특징 | 등장 |
|---|---|---|
| 꼬마 도깨비 | 느리고 약함, 무리 | 처음부터 |
| 도깨비불 | 빠르고 약함 | 33초~ |
| 방망이 도깨비 | 느리고 단단함 | 1분 20초~ |

## 7. 판 밖 성장 (영구 강화)
엽전으로 메인의 [강화]에서 강화. 모든 캐릭터에 공통 적용. 전체 49레벨.
| 항목 | 효과 (레벨당) | 최대 |
|---|---|---|
| 공격력 | +5% | 10 |
| 최대 체력 | +10 | 10 |
| 방어 | 받는 피해 -1 | 5 |
| 이동 속도 | +3% | 5 |
| 경험치 획득 | +5% | 5 |
| 아이템 획득 범위 | +10% | 5 |
| 엽전 획득 | +5% | 5 |
| 부활 | 1회 부활 | 1 |
| 다시 뽑기 | 레벨업 카드 다시 뽑기 +1 | 3 |
- 비용은 레벨마다 증가 (예: 100 → 150 → 225)
- 강화 초기화 시 엽전 전액 환급

**밸런스 목표** (보통 실력 기준. 강화 %는 49레벨 중 찍은 비율)
| 맵 | 클리어 가능한 강화 수준 | 대략 몇 판째 |
|---|---|---|
| 1. 들판 | 약 20% (10레벨) | 10판 안팎 |
| 2. 대나무 숲 | 약 45% (22레벨) | 25~30판 |
| 3. 달빛 궁궐 | 약 70% (34레벨) | 50~60판 |
| 4. 황천길 | 약 90% (44레벨) | 80~100판 |
- 강화 0에서는 들판에서 1분 20초~2분 버티는 수준이 목표 (지금 측정값은 평균 2분 7초: 부활이 없어 첫 보스가 나온 뒤 1분 30초~2분 30초 사이의 고비에서 대부분 끝난다)
- 무기 진화: 목표 강화 수준에서 카드를 아무거나 골라도 30~40%의 판에서 진화가 일어나는 정도 (호랑이 100판 측정: 들판 46% · 대나무 숲 30% · 달빛 궁궐 44% · 황천길 33%)
- 스킬 조합을 잘 고르면 이보다 낮은 강화로도 클리어 가능
- 강화 비용과 판당 엽전 획득량은 위 판 수에 맞춰 조정. 강화 수준과 맵을 지정해 바로 시험해 볼 수 있는 개발용 테스트 설정도 만들어 줘

## 8. 도감
만난 요괴·보스, 얻은 무기·패시브·진화 무기, 해금한 캐릭터를 기록. 못 만난 항목은 그림자로 표시. 진화 조합 힌트 제공.

## 9. 조작
- PC: WASD/방향키 8방향 이동, Esc 일시정지, 레벨업 카드는 1·2·3 또는 클릭
- 모바일: 화면 아무 곳이나 터치하면 그 자리에 가상 조이스틱, 오른쪽 위 일시정지 버튼
- 배속: 오른쪽 위 일시정지 버튼 옆의 배속 버튼(×1 ↔ ×2). 2배속이면 실제 시간 1초에 게임이 2초치 흐른다 (4분 판이 2분). 계산은 같아서 결과는 배속과 무관하고, 선택은 기기에 기억한다. 서버는 판에 걸린 실제 시간을 생존 시간 ÷ 2 기준으로 확인한다 (042·043. 여유 15초: 판 시작 알림이 늦게 닿은 판도 받는다, 045)
- 방향이 있는 무기는 마지막 이동 방향 또는 가장 가까운 적을 향함

## 10. 랭킹
- **맵별 생존 시간 랭킹** (맵 4개 각각)
- 정렬: 생존 시간(최대 4분) → 클리어한 기록이 위 → 처치 수 → 먼저 달성한 순
- 각자 맵별 최고 기록 하나만 등록, 누적 운영(초기화 없음)
- 표시: 순위, 캐릭터 아이콘, 아이디, 생존 시간, 처치 수, 달성 날짜. 내 순위는 목록 아래 항상 표시
- 상위 순위 아이콘은 다른 SIA-WORLD 랭킹과 통일
- **무한 모드 랭킹**은 4분 모드와 따로 맵별로: 생존 시간 → 처치 수 → 먼저 달성한 순. 랭킹 창의 서바이벌 탭에서 "4분 모드 / 무한 모드"를 바꿔 본다 (맵 탭·내 순위는 같다)
- **헬 모드 랭킹**도 따로 맵별로 (헬 맵 4개): 4분 모드와 같은 순서 (생존 시간 → 클리어 → 처치 수 → 먼저 달성). 랭킹 창에서 "4분 / 헬 / 무한" 순으로 바꿔 본다

## 11. 데이터 (Supabase, 기존 규칙에 맞춰 이름과 RLS 조정)
- `survival_profiles`: user_id, coins, upgrades(JSON), unlocked_characters, unlocked_maps, codex(JSON), updated_at
- `survival_records`: user_id, map_id, best_time, best_kills, cleared, character, achieved_at
- `survival_runs`: id, user_id, map_id, character, mode(normal·endless·hell), time, kills, level, coins_earned, cleared, created_at
- `survival_endless_records`: user_id, map_id, best_time, best_kills, character, achieved_at (무한 모드의 맵별 최고 기록)
- `survival_hell_records`: user_id, map_id, best_time, best_kills, cleared, character, achieved_at (헬 모드의 맵별 최고 기록, 뷰 `survival_hell_ranking`)
- 판이 끝날 때 한 번에 저장. 실패하면 기기에 임시 보관 후 다음 접속 때 재전송
- 비정상 기록(4분 초과, 지나치게 많은 처치 수 등)은 랭킹 등록 제외
- **처치 수 하한** (045, `game/progress.ts` 의 `killFloor`): 처치 수가 (생존 시간 − 120초) × 1 보다 적은 판은 세지 않는다 — 엽전 0, 기록(4분·무한 랭킹)·클리어·해금·누적·도감·시아코인 없음. 비정상 기록으로 치지는 않는다. "기다리기만 한 0킬 기록"을 꾸며 보내는 것을 막는 장치다
  - 기준: 밸런스 틀로 맵 4종 × 캐릭터 12종 × 강화 0·10·25·49 × 조작 3가지(보통 실력 · 가만히 서 있기 · 한쪽으로만 달리기) × 5판, 무한 모드(강화 49)까지 돌려 **판 도중 매 초**의 처치 수를 쟀다. 처음 1~2분은 거의 못 잡고도 살아 있는 판이 있어(황천길: 60초에 1마리, 90초에 16마리, 120초에 80마리가 최소) 2분 뒤부터만 본다. 2분 뒤로는 (처치 수 ÷ (시간 − 120초))의 최소가 초당 5.9마리(황천길 161초에 241마리)였고, 하한은 그 절반보다 훨씬 낮은 초당 1마리다
- 시아코인은 생존 시간이 1분 이상이고 **서버가 잰 실제 경과 시간도 1분 이상**인 판에만 (2배속으로 30초마다 받는 것 방지, 045)
