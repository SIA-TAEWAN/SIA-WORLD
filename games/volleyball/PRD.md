# 시아배구 구현 요청

SIA-WORLD 저장소(SIA-TAEWAN/SIA-WORLD, 로컬 C:\Claude\SIA-WORLD)에 새 게임 **시아배구**를 `games/volleyball`로 추가해 줘.
십이지 캐릭터로 1:1 온라인 대전 또는 AI 대전을 하는 세로 화면 웹 배구 게임이야.

## 0. 시작 전에 먼저 할 일
코드를 쓰기 전에 아래를 먼저 살펴보고, 무엇을 그대로 가져다 쓸지 짧게 보고해 줘.
- `games/tank`(시아탱크)의 폴더 구조, Phaser 3 설정, 씬 구성
- 통합 로그인(아이디+비밀번호), Supabase 클라이언트 설정, 기존 랭킹 테이블 구조
- 다른 게임들의 로비·대기방 구현 방식 (Supabase Realtime 채널/Presence 사용법)
- DESIGN.md (색, 글꼴, 버튼, 패널, 사운드 규칙)
- 십이지 캐릭터 이미지가 있는 위치와 형식
- SIA-WORLD 게임 선택 화면에 게임을 추가하는 방법
기존 공용 코드와 스타일을 최대한 재사용하고, 새로 만드는 것은 최소로 해 줘.

## 1. 기본 사항
- 기술: Phaser 3, Supabase Realtime + DB, 기존 배포 방식(GitHub Pages) 그대로
- 화면: **세로 9:16, 기준 해상도 720×1280**. PC에서는 화면 가운데에 세로 비율로 표시
- 화면 구역(위→아래): 점수판(약 160px) / 경기장(720×840) / 조작 버튼 영역(약 280px)
- 로그인 필수 (AI전 포함, 다른 게임과 동일)
- 캐릭터: 기존 십이지 12종. **외형만 다르고 능력치는 모두 같음**. 같은 캐릭터 선택 허용(좌우 구분은 이름표·테두리 색)

## 2. 화면 흐름
로그인 → 게임 선택 → 시아배구 로비 → 게임방(캐릭터 선택·레디) → 경기 → 결과

**로비**
- 방 목록: 방 이름, 방장, 인원(1/2, 2/2), 상태(대기중/경기중)
- 누구나 방 만들기 가능 (방 이름을 비워 두면 "OO의 방")
- 대기중이면서 1/2인 방만 입장 가능
- 방 링크 복사: 링크로 들어온 사람은 로그인 후 그 방으로 바로 입장
- [AI 대전] 버튼: 캐릭터 선택 후 바로 AI와 경기
- [랭킹] 버튼
- 방 비밀번호 없음

**게임방**
- 최대 2명. 먼저 들어온 사람이 왼쪽, 나중에 들어온 사람이 오른쪽
- 각자 캐릭터 선택 → 둘 다 레디하면 3초 카운트다운 후 시작
- 방장이 나가면 남은 사람이 방장이 되고, 혼자 남으면 대기 상태로 돌아감

**결과 화면**
- 승/패 표시. AI전이면 "연습 경기"로 표시
- [다시하기]: 두 사람 모두 누르면 같은 방에서 바로 재경기. 한 명이 나가면 남은 사람은 대기 상태
- [로비로]

## 3. 경기 규칙
- 네모난 방: 왼쪽 벽, 오른쪽 벽, 천장, 바닥. 가운데에 네트(바닥에서 솟은 기둥). 왼쪽이 1P 코트, 오른쪽이 2P 코트
- 공은 벽·천장·네트·캐릭터에 맞으면 튕김. 네트 윗부분은 둥근 면으로 처리
- 캐릭터에 맞으면 캐릭터 중심에서 공 쪽 방향으로 튕겨 나가고, 캐릭터 속도의 일부가 공에 더해짐 (점프하면서 치면 더 세게 날아감)
- 공이 **내 쪽 바닥**에 닿으면 상대가 1점
- **3점을 먼저 얻으면 승리. 듀스 없음**
- 터치 횟수 제한 없음
- 득점하면 1.5초 정지(득점 연출) 후 다음 서브
- 서브: 첫 서브는 랜덤, 그 뒤로는 **실점한 쪽**이 서브. 서브하는 캐릭터 머리 위에서 공이 떨어지며 자동으로 시작
- 캐릭터: 좌우 이동과 점프만 가능. 자기 코트 밖(네트 너머)으로는 못 감. 공중에서도 좌우 이동 가능
- **랠리 가속**: 서브 후 10초마다 공 속도 10% 증가(최대 속도 상한도 함께 올라가며 최대 +50%). 득점하면 기본 속도로 초기화. 빨라질 때 짧은 이펙트와 효과음
- 중도 이탈: 경기 중 나가거나 연결이 10초 넘게 끊기면 남은 사람 승리, 나간 사람은 패배로 기록

## 4. 물리 수치 (초안, 60fps 기준. 상수 파일 한 곳에 모아 쉽게 조정할 수 있게)
| 항목 | 값 |
|---|---|
| 중력 | 공 0.45, 캐릭터 0.8 (px/frame²) |
| 캐릭터 | 약 72×72px, 충돌 판정은 원형 |
| 이동 속도 | 5 px/frame |
| 점프 초기 속도 | 14 px/frame (높이 약 120px) |
| 공 지름 | 약 48px |
| 벽·천장·네트 반발 | 0.9 |
| 캐릭터에 맞았을 때 | 튕김 속도 최소 11 + 캐릭터 속도의 50% |
| 공 최대 속도 | 20 px/frame (가속 시 최대 30) |
| 네트 | 폭 12px, 높이 약 200px |
프레임 속도가 달라도 같은 결과가 나오도록 고정 타임스텝으로 계산해 줘.

## 5. 조작
- PC: ←/A 왼쪽, →/D 오른쪽, ↑/W/Space 점프
- 모바일: 아래 조작 영역에 ◀ ▶ (왼쪽), 점프 (오른쪽). 엄지로 누르기 좋은 크기, 멀티터치 지원
- 왼쪽 자리든 오른쪽 자리든 조작키는 같음

## 6. AI (보통 난이도 한 가지)
- 공이 자기 코트로 오면 떨어질 위치를 예측해 그쪽으로 이동하고, 공이 적당한 높이에 오면 점프
- 반응 지연 0.15~0.25초, 예측 위치 오차 ±20px
- 공이 상대 코트에 있으면 자기 코트 가운데 근처로 돌아감
- 목표: 이길 수 있지만 방심하면 지는 수준
- AI 캐릭터는 내 캐릭터를 뺀 십이지 중 랜덤
- AI전은 랭킹·전적에 기록하지 않음

## 7. 실시간 통신
- 방 하나 = Supabase Realtime 채널 하나. 방 목록은 Presence로 관리 (빈 방은 자동으로 사라짐)
- 호스트 권한: 방장(왼쪽) 기기가 공 물리·득점·점수를 계산
  - 각자 자기 캐릭터의 입력과 위치를 브로드캐스트
  - 방장은 공 상태와 점수를 초당 약 20회 전송, 상대 기기는 그 사이를 보간
- Presence로 연결 끊김 감지 (10초)
- 경기가 끝나면 방장 기기가 결과를 DB에 저장
- 지연 때문에 상대 쪽 화면에서 공을 친 판정이 어색하면, 상대 기기에서도 튕김을 미리 예측해 보여 주는 방식을 검토

## 8. 랭킹과 데이터
- 사람 대 사람 경기만 기록. **누적 기록만 쌓고 초기화 없음**
- 정렬: 승수 → 승률 → 먼저 달성한 순
- 랭킹 화면: 순위, 캐릭터 아이콘(최근 사용), 아이디, 승, 패, 승률
- 상위 순위 아이콘은 시아탱크 랭킹 방식과 맞춤
- 테이블(기존 규칙에 맞춰 이름과 RLS 조정):
  - `volleyball_rankings`: user_id, wins, losses, last_character, updated_at
  - `volleyball_matches`: id, left_user_id, right_user_id, left_score, right_score, winner_id, ended_reason(정상/이탈), created_at
- 사용자 정보는 통합 로그인 계정 테이블 사용

## 9. 디자인과 사운드 (DESIGN.md 기준)
- UI 스타일은 DESIGN.md를 그대로 따름
- 경기장 배경: **십이지 테마 3종, 경기마다 랜덤**. 벽·바닥·네트의 위치와 크기는 셋 다 같음
- 공: 평범한 배구공 1종
- 캐릭터: 기존 십이지 디자인을 그대로 쓰고, 대기·이동·점프 동작만 추가
- 점수판(화면 위쪽): 왼쪽 캐릭터 얼굴·아이디·점수 | 오른쪽 동일
- 그림이 아직 없으면 임시 도형으로 먼저 만들고, 필요한 에셋 목록을 따로 정리해 줘 (나중에 SpriteCook으로 제작)
- 사운드: 로비 BGM, 경기 BGM, 점프, 캐릭터 타격음, 벽·네트 튕김, 가속, 득점, 승리/패배, 카운트다운. 소리 켜기/끄기 버튼은 다른 게임과 같은 위치

## 10. 하지 않는 것
스파이크·다이브·스킬, 캐릭터별 능력치, 2:2, 관전, 자동 매칭, 결제·아이템, AI 난이도 여러 단계, 방 비밀번호, 게스트 플레이, 경기 중 이모티콘·채팅(나중에 고려)

## 11. 진행 순서
단계마다 직접 실행해서 확인하고, 결과를 보고한 뒤 커밋하고 다음 단계로 넘어가 줘.
1. 혼자 하는 버전: 경기장, 공 물리, 캐릭터 이동·점프, 득점, 3점 승리, 랠리 가속 (임시 그림)
2. AI 대전 + 결과 화면
3. 온라인 대전: 로비, 게임방, 캐릭터 선택, 레디, 동기화, 이탈 처리, 다시하기
4. 랭킹: 결과 저장, 랭킹 화면
5. 디자인·사운드 적용: DESIGN.md, 배경 3종, 효과음
6. SIA-WORLD 연결: 통합 로그인, 게임 선택 화면에 추가, 배포
