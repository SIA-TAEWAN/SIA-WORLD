# 시아배구 — 그림·소리 현황과 나중에 만들 것

지금은 **모두 코드로 그린 그림**으로 돌아간다 (DESIGN.md 색·외곽선 규칙). 캐릭터만 공용 십이지 그림
(`shared/images/zodiac/full/<id>.png` 전신, `face/<id>.png` 얼굴)을 쓴다.

정식 그림은 SpriteCook으로 만들어 아래 **파일 이름**으로 `games/volleyball/public/art/`에 넣고,
`src/scenes/art.ts`의 `ART_FILES`에 그 이름을 적는다. 그러면 그 그림을 먼저 쓰고, 못 불러올 때만 코드 그림으로 대신한다 (시아레이스와 같은 방식).
파일을 넣지 않은 이름은 `ART_FILES`에 적지 않는다 (경기마다 404 요청이 나간다).
원본 시트와 asset id는 `games/volleyball/art/`, `games/volleyball/spritecook-assets.json`에 남긴다.

스타일: 굵은 갈색 외곽선(`#2A1A10`), 밝은 단색, 흐린 그림자 없음, 장난감·스티커 느낌 (DESIGN.md).

## 경기장 좌표 (모든 배경이 같아야 하는 자리)

경기장은 **720×840** (그림은 2배인 1440×1680). 값은 `src/game/constants.ts`.

| 자리 | 위치 |
|---|---|
| 벽·천장 두께 | 16px (왼쪽 x 0~16, 오른쪽 x 704~720, 천장 y 0~16) |
| 바닥 선 | y = 776 (그 아래 64px는 바닥 그림) |
| 네트 | 가운데 x = 360, 폭 12, 높이 200 (y 576~776), 윗부분은 반지름 6의 둥근 면 |
| 공 | 지름 48 |
| 캐릭터 | 판정 원 지름 72, 그림 높이 약 86 |

- 정식 그림은 **벽·천장·바닥까지 한 장**에 그린다 (그림이 있으면 코드는 벽·바닥·깃발을 그리지 않는다). 네트·공·캐릭터는 따로 올린다.

- 테스트: `?local=1&bg=0~2` 로 배경을 골라 볼 수 있다.

## 3. 캐릭터 동작

전신 그림 한 장을 코드로 움직인다: 대기(숨쉬기) · 이동(가는 쪽으로 기울이고 통통) · 점프(올라갈 때 길쭉, 내려올 때 납작) · 착지(찌그러졌다 복원) · 타격(살짝 커짐).
캐릭터 뒤의 옅은 원이 판정 범위이고, 테두리 색(왼쪽 파랑·오른쪽 빨강)과 이름표로 좌우를 구분한다.
→ **새 그림이 필요 없다.** 동작을 그림으로 바꾸려면 `shared/images/zodiac/volley/<id>-idle|move|jump.png` (240×240, 12종 × 3). 우선순위 낮음.
