# 시아배구 — 필요한 정식 그림·소리 목록

지금(1·2단계)은 모두 **임시 그림**이다: 경기장·벽·바닥·네트·공·이펙트는 코드로 그린 도형(`src/scenes/art.ts`, `src/scenes/CourtScene.ts`의 `drawCourt`),
캐릭터는 공용 십이지 전신 그림(`shared/images/zodiac/full/<id>.png`) 한 장을 코드로 움직인다.

정식 그림은 SpriteCook으로 만들어 아래 파일 이름으로 `games/volleyball/public/art/`에 넣고, `src/scenes/art.ts`의 `ART_FILES`에 이름을 적는다
(시아레이스와 같은 방식: 파일을 먼저 쓰고, 못 불러오면 코드 그림으로 대신). 원본 시트와 asset id는 `games/volleyball/art/`, `games/volleyball/spritecook-assets.json`에 남긴다.

스타일은 DESIGN.md: 굵은 갈색 외곽선(`#2A1A10`), 밝은 단색, 흐린 그림자 없음, 장난감·스티커 느낌.

## 경기장 좌표 (모든 배경이 같아야 하는 자리)

경기장 그림 크기는 **720×840** (2배로 그릴 때 1440×1680). 값은 `src/game/constants.ts`.

| 자리 | 위치 |
|---|---|
| 벽·천장 두께 | 16px (왼쪽 x 0~16, 오른쪽 x 704~720, 천장 y 0~16) |
| 바닥 선 | y = 776 (그 아래 64px는 바닥 그림) |
| 네트 | 가운데 x = 360, 폭 12, 높이 200 (y 576~776), 윗부분은 반지름 6의 둥근 면 |
| 공 | 지름 48 |
| 캐릭터 | 충돌 원 지름 72, 그림 높이 약 86 |

## 1. 배경 3종 (경기마다 무작위, 벽·바닥·네트 자리는 셋 다 같음)

| 파일 | 크기 | 내용 |
|---|---|---|
| `bg-1.png` | 1440×1680 | 십이지 테마 1 (예: 봄 들판 — 쥐·소·호랑이·토끼 장식) |
| `bg-2.png` | 1440×1680 | 십이지 테마 2 (예: 여름 바닷가 — 용·뱀·말·양 장식) |
| `bg-3.png` | 1440×1680 | 십이지 테마 3 (예: 가을 마당 — 원숭이·닭·개·돼지 장식) |

- 벽·천장·바닥까지 한 장에 그린다. 네트와 공·캐릭터는 따로 올린다.
- 공과 캐릭터가 잘 보이게 경기장 안쪽(하늘 부분)은 밝고 단순하게. 왼쪽·오른쪽 코트 구분(파랑 `#3D8BFF` / 빨강 `#FF4D6D`)은 코드가 바닥 띠로 덧그린다.
- 로비·방 목록 썸네일용 축소판은 같은 그림을 줄여 쓴다 (따로 만들지 않음).

## 4. 캐릭터 동작

- 지금 방식(전신 그림 한 장을 코드로 움직임: 대기 숨쉬기 · 이동 기울이기·통통 · 점프 늘어남 · 착지 찌그러짐 · 타격 때 살짝 커짐)을 유지하면 **새 그림이 필요 없다**.
- 동작을 그림으로 바꾸고 싶으면 캐릭터마다 `shared/images/zodiac/volley/<id>-idle.png`, `-move.png`, `-jump.png` (각 240×240, 12종 × 3 = 36장). 우선순위 낮음.

## 6. 소리 (`shared/sound.js`, 5단계에서 다듬기)

지금은 공용 효과음 가운데 이미 있는 이름을 빌려 쓴다. 전용 소리가 필요하면 `shared/sound.js`에 ZzFX 값으로 추가하거나 `shared/sounds/<이름>.ogg`를 넣는다.

| 상황 | 지금 쓰는 소리 | 전용으로 만들 이름 (제안) |
|---|---|---|
| 점프 / 착지 | `jump` / `land` | 그대로 |
| 캐릭터 타격 | `slap` (세기에 따라 높이·크기 조절) | `volleyHit` |
| 벽·천장 튕김 | `flip` | `volleyWall` |
| 네트 튕김 | `fold` | `volleyNet` |
| 랠리 가속 | `boost` | `volleySpeed` |
| 득점 / 실점 | `goal` / `bust` | `volleyPoint` / `volleyMiss` |
| 승리 / 패배 | `win` / `lose` | 그대로 |
| 카운트다운 3·2·1 / 시작 | `raceReady` / `raceGo` | 그대로 |
| 배경음 | 코드로 만든 반복곡 (`src/ui/music.ts`) | `shared/sounds/bgmLobby` · `bgmVolley` · `bgmResult` (.ogg 또는 .mp3) |
