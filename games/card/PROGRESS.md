# 시아카드배틀 진행 기록

기준: `PRD.md` (사용자 스펙 + 메인이 정한 것). 개발 서버 `npm run dev` → `http://localhost:5300/games/card/?local=1`.

## 1단계 — 전투 시뮬레이션 + 카드 20장 + 요괴 4종 (완료)

- 규칙 코드 `supabase/functions/_shared/card/` (Deno 규칙: `.ts` 확장자 상대 import, Node/브라우저 전용 API 없음)
  - `rng.ts` 씨앗 난수(mulberry32, 상태 = 숫자 하나) · `hashSeed`
  - `types.ts` 카드·요괴·부적·사건 데이터 타입 — 효과는 작은 연산 목록(`Op` 카드·물약 / `EOp` 요괴 / `EvOp` 사건)
  - `state.ts` 판·전투 상태(JSON), 입력(`Input`), 연출 사건(`SimEvent`)
  - `battle.ts` 전투 규칙: 기력 3(이월 없음) · 5장 · 손패 10 · 더미 섞기 · 방어(내 턴 시작에 사라짐) · 화상/독/젖음/진흙/약화 + 힘 · 소멸 · 부적술 · 내림카드 · 의도 5종 · 보스 2단계(50%) · 소환 · 피하기 · 부적 30개 효과
  - `text.ts` 카드 설명을 연산에서 만든다 (숫자가 데이터와 늘 같음)
  - `data/*.ts` 카드·영웅·요괴·부적·물약·사건·막 데이터 → `games/card/src/data/*.json` 은 `npm run json` 이 만든 사본(`tests/data.test.ts` 가 같은지 확인). 데이터를 고치면 `npm run json`.
- 화면: Vite + TS + Phaser 3, 세로 430×860 (`Scale.FIT`). 전투 `src/scenes/BattleScene.ts`, 코드 그림 `src/scenes/art.ts`. 영웅은 `shared/images/zodiac/full|face/<id>.png` (못 읽으면 코드 그림/숨김).
  - 카드: 끌어서 요괴 위(대상 카드)·위쪽(그 밖)에 놓기, 또는 탭해서 고르고 한 번 더 탭(대상 카드는 요괴 탭). 물약은 위 줄 동그라미를 두 번 탭. 요괴를 탭하면 다음 행동·상태 설명, 더미를 탭하면 목록.

## 2단계 — 지도·보상·상점·쉼터·보물·이야기, 1막 완성 (완료)

- `map.ts` 갈림길 지도: 12줄 + 보스, 한 줄 2~4칸, 가장 가까운 칸끼리 잇고(엇갈림 없음) 옆 이음을 조금 더함. 칸 종류는 막 전체 칸 수 × 스펙 비율(큰 나머지 반올림)을 섞어 배치. 보물 지도 = 보물 +2.
- `run.ts` 판 진행: `apply(run, input)` · `replay(seed, hero, log)`. 칸마다 쓰는 난수는 `hashSeed(씨앗, 종류, 막, 줄, 칸)` 로 따로 → 한 칸의 선택이 다른 칸의 지도·보상·상점을 바꾸지 않음 (오늘의 도전 준비).
  - 전투: 처음 3번은 쉬운 조합, 그 뒤 보통 조합. 보상 엽전 12~18(정예 25~35, 보스 60) + 카드 3장 중 1장(건너뛰기) + 물약 40%. 정예 = 막 보스가 아닌 그 지역 보스 2마리 중 하나(체력 60%) + 부적.
  - 막 보스 승리: 체력 절반 회복 · 전설 카드 고르기 · 보스 부적 3개 중 1개 → 다음 막(아직 없으면 판 클리어). 시아코인은 5단계.
  - 상점: 카드 5(일반 50~70 · 고급 80~110 · 전설 130~150) · 부적 2(일반 150~200 · 고급 220~300) · 물약 2(40~60) · 카드 없애기 75(+25씩, 상점마다 1번, 덱 최소 5장).
  - 쉼터: 체력 30% 회복(토끼 +10 · 산삼 +15 · 여의주 조각이면 불가) 또는 카드 1장 강화(대장간 망치 2장).
  - 보물: 부적 1개. 이야기: 12개 사건 데이터 전부 + 선택지 처리(1막에는 '전체'·'1막' 사건만, 한 판에 같은 사건 한 번).
- 화면 `src/ui/app.ts`: 처음(이어하기·새 판 / 오늘의 도전·끝없는 모드·도감·랭킹은 '준비 중') → 영웅 고르기(13칸, 지금은 어흥이만) → 지도(위로 스크롤, 맨 위 보스) → 칸 화면들 → 결과. 덱 보기·부적 설명·물약 버리기는 위 줄에서.
- 저장: `localStorage` (`siacard:run`, 테스트 모드 `siacard:local:run`, try/catch). 칸에 들어간 순간(`go`)과 전투 밖의 입력마다 저장, 전투 중 입력은 저장하지 않음 → 전투 중 종료하면 그 전투 처음부터 (같은 씨앗이라 같은 손패).
- 개발용 주소: `?local=1&seed=5&gold=500&relics=moonOrb,whetstone` (새 판에 적용), `&reset=1` 저장 지우기, `&foes=fox,acorn&kind=boss` 바로 연습 전투. 처음 화면의 '개발: 연습 전투'.

  - `src/art.ts`: `ART_FILES`(목록에 있는 것만 받음) · `artUrl`(`?v=` 빌드 판본) · 시트 칸 번호 · 카드 틀 자리(`FRAME`) · `fxForCard` · `preloadUi`(카드 틀·지도 칸 시트를 처음 화면 전에 읽어 보고 못 읽으면 코드 그림). `tests/art.test.ts` 가 폴더 = 목록, 데이터 그림 이름이 다 있는지 본다.
  - 전투: 배경 `bg-<지역>`, 영웅 시트 `hero-<id>`(앞줄 서기·공격 칸; 못 읽으면 공용 전신 → 코드 그림), 요괴 `e-*`·`b-*`, 카드 = 카드 그림 → 틀(종류색 곱하기) → 흰 설명 칸 → 기력 구슬 → 등급 테두리, 의도 시트, 기력 구슬 `energy`, 뽑을 더미 `back`, 상태이상 `st-*` 의 꽉 찬 칸을 동그랗게 잘라 씀, 물약·부적 아이콘.

## 4단계 — 2~3막, 보스 12종 + 어둑시니, 부적 30, 이야기 12, 카드 86장 (완료)

- **막**: 1막 대나무숲·들판 무작위, 2막 궁궐, 3막 저승 (`data/acts.ts`). 지역마다 일반 요괴 4종(행동 2~4개, 막이 오를수록 체력·피해 큼 — 저승 원귀 `spirit3` 는 궁궐 원혼과 같은 그림의 센 판) + 쉬운/보통 조합. 막마다 앞쪽 일반 전투는 쉬운 조합(1막 3번, 2·3막 2번, `run.actBattles`).
  - 막 보스 승리: 체력 절반 회복 · 전설 카드 3장 중 1장 · 보스 부적 3개 중 1개 → 다음 막(`actStart` 에 위치 기록). 3막 보스 뒤 = 일반 엔딩(`run.ending = 'normal'`).
  - **숨은 4막**: 정예 3마리 이상(`FINAL_ELITES`, 갈림길의 여우 포함) + 3막 클리어 → 지역 `abyss`(어둠의 끝, 저승 그림)의 보스 한 칸 지도 → 어둑시니. 이기면 보상 없이 진짜 엔딩(`ending = 'true'`). 화면: 지도 대신 입구 장면(`ending-4`).
- **보스 12종 정식 패턴 + 어둑시니** (`data/enemies.ts`, 새 요괴 연산·단계 특성은 `battle.ts`)
  - 구미호 2단계 '매 턴 분신1'은 `turnOps` 로. 장산범 2단계 덮치기·덮치기·숨기. 큰도깨비 금 나와라(방어15+힘2) / 방망이 9×2 · 도깨비 장난2(뽑을 더미). 불가살 2단계 `revive`(쓰러지면 한 번 30%, 화상이면 못 함). 강철이 메마름(`halveBlock`) / 2단계 `scorch`(매 턴 화상2, 내 화상 피해 2배, 젖음 1당 내 화상 -2). 수문장 대장 방패벽+병졸1 / 병졸 부르기2(최대 3)·화살 비5×4. 두억시니 2단계 매 턴 힘+3. 이무기 2단계 승천 예고 2턴 → 대해일35, 예고 중 피해 40이면 취소(`charge` → '떨어짐' → 물보라부터). 저승사자 이름 부르기(저승 사슬1) / 낫10×2 + `execute`(내 체력 30% 이하 피해 2배). 야광귀 신발 훔치기(`drain`, 다음 턴 기력-1) / 어둠 속(`dark`, 받는 피해 -75%, 화상을 걸거나 다음 행동이면 풀림). 염라대왕 심판20 → 업보(`karma`, 이 전투 공격카드 수×2) → 저승 사슬2 / 저승사자(체력60) 소환 + 매 턴 업보.
  - 어둑시니 450: `rage`(공격카드 쓸 때마다 힘+1), `phaseAt [0.66, 0.33]` 3단계, 그림 `grow [230, 262, 296]`(발밑 고정으로 커지는 연출 + '커졌다!' 컷인), 덮침12 / 덮침 8×3.
  - 단계는 일반화(`phase: 1|2|3`, `phaseAt`), `foeHits(run, b, f)` = 다음 차례 공격(매 턴 행동 + 의도, 업보·저승사자 2배 포함) — 화면 의도 숫자와 봇이 같이 쓴다.
- **부적 30개** 전부 효과·테스트(`tests/relics.test.ts`). 보물 지도는 얻은 순간 지금 막의 남은 전투 2칸도 보물로 바꾼다.
- **이야기 사건 12개**: 막 조건대로, 한 판에 같은 사건 한 번 — 그 막에 볼 사건이 없으면 보물 칸이 된다. 갈림길의 여우 = 정예 '천년 여우'(`foxElite` 1막 · `foxElite2` 2막, 그림 `e-fox-elite`) 보상 2배.
- **카드 86장** = 기본 2 + 일반 28 + 고급 20 + 전설 10 + 영웅 전용 26 (+내림카드 2). 새 연산: 이기면 엽전 · 다음 카드 기력-1 · 겨누기 · 무작위 손패 기력0 · 다음 턴 더 뽑기 · 상태이상 막기 · 독 퍼뜨리기 · 시간 멈춤 · 흡혈 · 젖은 적 ×2 · '이미 화상이면 +2'. 부적술 3종 더(독사의 길 `poisonUp`, 무한 부채 `drawBlock`, 불사조 깃 `phoenix`), 날랜 몸·수호신·십이지 대진(`drawUp`·`guard`·`energyUp`)도 구현. 설명은 연산에서 만들고, 앞 연산도 '모든 적'이면 상태이상의 '모든 적'을 줄인다(용의 숨결 '모든 적 10, 화상2').
- **카드 설명 칸 맞추기** (`src/ui/fit.ts`): 칸(78×31)에 들어가는 가장 큰 글자(11 → 7.5px)와 빈칸 기준 줄바꿈을 골라 전투 카드·HTML 카드 둘 다 쓰고, 실제로 그린 크기가 넘치면 더 줄인다(캔버스 `descText`, HTML `shrinkOverflow`). 확인: `tests/fit.test.ts`(86장+강화 × 두 칸), 브라우저 `?local=1` 전투에서 `window.__cardFit()` → `[]` (확인함: 캔버스 넘침 0, HTML 덱 보기 176장 넘침 0).
- **화면**: 2·3막 배경·지도 바닥(지역 데이터), 새 막 알림, 보스 보상 버튼('2막으로 ▶' · '엔딩 보기 ▶'), 숨은 4막 입구, 엔딩 장면(일반 `ending-2 → ending-3` · 진짜 `finale-1 → finale-2 → finale-4`) → 결과. 연출 사건 더함: 부활 · 승천 저지 · 시간 멈춤 · 어둠 속 · 상태이상 막음 · 기력 빼앗김, 요괴를 누르면 단계 특성 설명. 연습 전투 메뉴에 지역 전투·천년 여우·보스 13종.
- 개발 주소 더함: `&act=2|3|4`(새 판을 그 막에서) · `&elites=3` · `&ending=normal|true`(엔딩 화면 바로), `&foes=final&kind=boss`.

## 입력 기록 형식 (5단계 서버 재실행용)

`run.log: Input[]` — 받아들인 입력만 순서대로 쌓임 (`state.ts` 의 `Input`). `run.actStart[]` = 막마다 시작한 log 위치.

| 입력 | 뜻 |
|---|---|
| `{t:'go', col}` | 지도에서 다음 칸 (보스 줄은 col 0) |
| `{t:'play', uid, target?}` | 카드 사용 — uid = 덱 카드 번호(전투에서 생긴 카드는 90000~), target = 요괴 번호 |
| `{t:'potion', slot, target?}` · `{t:'dropPotion', slot}` | 물약 사용 · 버리기 |
| `{t:'end', keep?}` | 턴 끝 (keep = 달빛 구슬로 남길 카드) |
| `{t:'pick', uid}` | 전투 중 손패 고르기 (쥐구멍 버리기 · 분신술 복사, 3단계) |
| `{t:'take', i, pick?}` | 보상 항목 받기 (카드·보스 부적은 pick 번째) |
| `{t:'buy', kind, i}` · `{t:'remove', uid}` | 상점 |
| `{t:'heal'}` · `{t:'upgrade', uids}` | 쉼터 |
| `{t:'open'}` | 보물 상자 |
| `{t:'choose', i}` · `{t:'pickCard', uid}` | 이야기 선택지 · 카드 고르기 |
| `{t:'leave'}` | 칸 마치고 지도로 (보스 보상이면 다음 막 · 3막이면 엔딩 또는 숨은 4막) |

숨은 4막도 같은 입력: 지도는 보스 한 칸(`{t:'go', col:0}`), 이기면 `phase = 'won'`, `ending = 'true'`.

전투 무작위는 전투마다 줄기 3개(`rng.draw` 섞기 · `rng.ai` 요괴 체력·의도 · `rng.fx` 무작위 대상·버리기)로 나뉘어 있어, 한쪽을 더 쓰더라도 다른 쪽 순서는 바뀌지 않는다.
같은 씨앗 + 같은 입력 = 같은 상태 (`tests/battle.test.ts`·`tests/run.test.ts` '결정성', `replay`). 서버는 막 단위로 `replay(seed, hero, log.slice(0, actStart[n+1]))` 를 돌리면 된다.

## 6단계 — 봇 밸런스 · 연습 전투 · 처음 만나는 말풍선 · 코인 고침 · 로비 확인 (완료)

### 봇을 '그럴듯한 사람'으로 (`scripts/smart-bot.ts`)

예전 단순 봇(`tests/bot.ts`, 테스트용으로 그대로 둠)은 카드 점수표만 보고 써서 3막 클리어 2~11% — 수치보다 봇이 문제였다. 새 봇은 화면과 같은 입력(`apply`)만 쓴다.

- **전투**: 쓸 수 있는 카드·물약(같은 카드·같은 요괴는 한 번)을 복사본에서 실제로 써 보고, 그 뒤 한 장 더(상위 5개 후보)까지 본 다음, 턴을 끝내 요괴 차례가 지난 상태를 점수로 매겨 가장 좋은 것을 고른다. 나아지는 게 없으면 턴 끝.
  - 점수: 내 체력(35% 아래는 더 비쌈) − 요괴 체력(분신·병졸은 0.6) + 쓰러뜨림 + 걸어 둔 독·화상(남은 총피해)·약화·젖음 − 요괴 힘 − 내 상태이상 + 다음 턴 방어(들어올 피해까지)·기력·손패 + 부적술(남은 턴 수만큼) − 내림카드 + 남겨 둔 물약 값(일반 전투 24 · 정예·보스 6 → 일반 전투에선 아끼고 큰 싸움·쓰러지기 직전엔 씀) − 한 번뿐인 부활(고양이·쇠조각·불사조) 써 버림.
  - 불가살: 아직 부활 안 했고 화상이 없으면 '30% 로 다시 일어남'을 남은 체력으로 센다 — 이걸 안 하면 봇이 마무리를 피하다 질질 끌려 죽었다(처음 측정에서 들판 정예 불가살 47% 의 원인. 고친 뒤 5%).
  - 복사본에서 뽑기 카드를 쓰면 실제로 뽑힐 카드를 미리 보는 셈이라 아주 조금 유리하다(의도는 사람도 보는 정보).
- **판**: 지도는 남은 길을 모두 따라가며 체력·엽전 흐름으로 점수(쉼터는 체력 낮을 때·보스 앞, 상점은 엽전 많을 때, 정예는 체력 75% 넘을 때만 조금 — 정예를 많이 찾는 봇은 클리어율이 크게 떨어져 '사람처럼' 가끔만). 카드 보상은 카드 값표 + 덱 구성(공격·방어 비율, 광역, 독·화상·젖음 짝, 같은 카드·부적술 많음)으로 덱 평균보다 1.2 이상 좋을 때만(덱 18장 넘으면 더 까다롭게). 상점은 카드 없애기(내림카드 → 베기 → 막기) → 좋은 부적 → 좋은 카드 → 물약. 쉼터는 체력 50% 아래·보스 앞 80% 아래면 회복, 아니면 값 높은(기력이 주는 강화 우선) 카드 강화. 이야기는 사건마다 정한 규칙(체력·엽전 보고).
- 측정: `npm run bot -- <판 수> [영웅,…] [--mastery=all|0,3] [--endless] [--diag] [--simple] [--workers=9]` — 9개 프로세스, 영웅마다 300판 약 2분. `--diag` 는 막·지역·보스별 쓰러짐과 잃은 체력. 무거워서 `npm test` 에는 봇 한두 판만(`tests/smartbot.test.ts`).

### B. 정해서 진행한 것 (다르면 알려 주세요)

1. 1막 일반 요괴 수치: 대나무 요괴 36~40(죽창9/방어8/힘+2) · 여우 26~30(할퀴기6 → 여우불3+화상2 → 약화1) · 도토리 14~18(5/방어5) · 스라소니 44~48(힘+2 → 11 → 4×2 → 11). 들판: 몽둥이 도깨비 40~44(10/힘+2/방어7) · 꼬마 도깨비 20~24(꼬집기5 → 장난: 도깨비 장난1) · 도깨비불 22~26(불똥4+화상2 / 깜빡: 피하기1) · 불수레 46~50(화상3 → 12 → 방어10 → 12). 전투 조합(1~3마리), 막마다 앞쪽 쉬운 조합(1막 3번, 2·3막 2번).

4. 지도: 첫 줄은 모두 전투, 정예는 4번째 줄부터, 보스 앞 쉼터 고정 없음(비율 유지). 그 막의 사건을 다 봤으면 이야기 칸은 보물 칸.
